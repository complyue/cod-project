## CCs, minicolumns and context

The [connectivity literature review](ConnectivityScalingResearch.md) distinguishes target-neuron count, synapse multiplicity, weight strength and coarse brain-region connectivity. Biological distributions are candidate priors for this application; they do not select a learning rule or a universal human exponent.

A CC is the basic unit of semantic presentation and represents one instantaneous semantic vector. H-43 states that CCs are approximate, non-exact replicas: they reuse the semantic presentation organization, without requiring identical learned connections, experience or instantaneous state. The precise cross-CC correspondence and cooperation protocol remain open. Minicolumn/neuron semantic roles are assigned statically; discovering or reassigning those roles is not a required learning task. Under the user's mapping, dimension `d` has a minicolumn/dimension group containing separate polarity populations. H-27's current case is **5,120 dimensions with 60 positive + 60 negative cells each**, giving **614,400 neurons**. [Signed populations](SignedPopulationEncoding.md) tracks the decoder and context/phase questions for this case. CCs exchange activation states as token-semantic-vector sequences. State precision includes FP16/FP32 candidates under H-73; FP8 or integer connection values and probabilistic input distribution require field-specific semantics and analysis.

H-46 clarifies that a measured biological feature need not correspond one-to-one with a minicolumn. A meaningful input or recurrent pattern can engage many coordinate populations; a coordinate population can participate in many features. Fixed coordinate roles do not imply one-coordinate token activation. This non-bijection is compatible with the model and does not require a new physical layout.

H-44's anatomical question remains separate. A coordinate/polarity assignment, a soma position, axon–dendrite contact opportunity and a storage address are distinct. [Anatomical compatibility research](SemanticCorticalMappingResearch.md#anatomical-compatibility-of-assigned-semantic-populations) assesses additional spatial assumptions; it does not select interleaving, new cell types, morphology or a position representation. Statistical symmetry over layouts differs from per-source equal proposals; H-41 establishes dimension neutrality but does not select that full probability contract.

HTM supplies a useful distinction: cells in one minicolumn share feedforward input but respond to different temporal contexts through distal dendritic segments. Predicted cells activate selectively when matching input arrives; an unexpected active column can burst. This is the source's sequence-memory model, not evidence that an arbitrary continuous embedding already has an HTM representation. [Hawkins and Ahmad (2016)](https://www.frontiersin.org/journals/neural-circuits/articles/10.3389/fncir.2016.00023/pdf).

H-75 explicitly identifies the different cells within a minicolumn with different contextual paths for the same semantic component. Their learned identities therefore carry information beyond the instantaneous aggregate vector. The coordinate/polarity role is fixed; context-sensitive paths are expressed through the individual cells and their connections. This does not require redefining each cell as a new embedding dimension or adding a separate context store.

**Current storage discussion:** H-21 provisionally retains the [alpha-near-3 static template](ConnectivityScalingResearch.md#candidate-static-layout) and asks to evaluate [target-owned incoming sets](IncomingConnectivity.md). Each proposed incoming slot stores a source ID and one-byte weight in parallel arrays; its common target is recorded once per set. A neuron points to its current set within fixed pools and may migrate without heap allocation. The preceding source-owned layout remains the comparison in [AdaptiveConnectivity](AdaptiveConnectivity.md). The 100-slot physical minimum can transfer to incoming capacity, but H-19’s permission to omit low-outgoing-degree influence does not imply that few-input neurons are unimportant. Admission, output suppression and re-entry remain separate decisions. Prediction-guided input and intrinsic polarity cancellation are specified separately; neither requires a learned dense `m×m` block in every minicolumn. HTM does not forbid every within-column connection.

In Numenta's Temporal Memory, a segment detects a pattern of active presynaptic cells. A synapse's permanence determines whether it is connected; the connected effect is binary. Permanence is therefore not the same quantity as an arbitrary signed FP8 synaptic weight. [Temporal Memory Algorithm Details](https://numenta.com/assets/pdf/temporal-memory-algorithm/Temporal-Memory-Algorithm-Details.pdf).

Graded rate dynamics, contextual cell identities and prediction-guided token entry are current modeling directions; their complete transition and readiness representation remain open. HTM coincidence/segment mechanisms remain references. H-79 confines Hebbian/HTM learning to token-sequence flow, and H-80/H-81 open its algorithm design separately from DMN/token construction and repair. Neither five-byte ownership variant specifies dendritic-segment boundaries; explicit segment semantics need a separate design. H-15 concerns outgoing fan-out. Under incoming ownership a source with 10,000 outputs appears across other neurons’ sets, while a 12,800-slot set limits its owner’s incoming capacity. The [ownership analysis](IncomingConnectivity.md#compatibility-with-the-capacity-law) keeps these distinct.

Context-dependent selection among cells remains a modeling question within their assigned semantic role. It does not authorize changing that role. Decide where the coordinate's magnitude and sign reside, how context chooses cells, and how dense signed vectors produce sparse activity. Preserving all input coordinates does not require activating every column at every step, but any sparsification changes the code and needs an error/meaning contract. Canonical HTM's sparse-input assumptions cannot simply be inherited.

## SNN-01 — Signed coordinates and output

Coordinate polarity, semantic valence, neuronal phase and synaptic excitation/inhibition are distinct meanings. Nonnegative activity can produce signed coordinates through a signed decoder; spikes do not need a negative amplitude. Semantically negative content is a property of a multidimensional pattern in context, not membership in the negative-coordinate population.

H-54 excludes explicit inhibitory synaptic connections from the early model and requires intrinsic cancellation between each dimension’s positive and negative populations. H-77 specifies the active-rate operation: calculate the minicolumn-wide net, zero the losing polarity and proportionally retain the surviving cells’ rates; an equal total cancels both active populations. There is no cell-index pairing. Placement within the transition remains open, and H-85 keeps predictive cancellation as an experimental alternative. The operation changes internal activity without a stored inhibitory matrix. [Signed population encoding](SignedPopulationEncoding.md#cancellation-arithmetic-and-the-semantic-residual) distinguishes activity reduction from the signed residual and its semantic meaning.

Within the opponent populations, compare count/fraction encoding with graded contributions while preserving fixed coordinate roles and contextual cell identities. Their calibration, decoder, range and precision remain open; [magnitude and contextual selection](SignedPopulationEncoding.md#magnitude-and-contextual-cell-selection) states the alternatives and their requirements. The current direction retains the two polarity populations and their intrinsic active-rate cancellation.

The current case sizes [60+60 populations](SignedPopulationEncoding.md) using Flash embeddings. Population readout with signed coefficients has established precedents, including [Nengo's NEF example](https://www.nengo.ai/nengo/v4.0.0/examples/advanced/nef-algorithm.html); that does not settle this application's HTM/context encoding. In particular, current activity, predictive activity and contextual bursting need distinct readout semantics. The [human V1 comparison](SignedPopulationEncoding.md#human-cortical-column-scale-reference) distinguishes measured tissue density from estimated module populations; it establishes no biological equivalence for our software CC.

As an illustration only, for an even `m` split equally into two independently sampled binary populations, use activation probabilities `max(u,0)` and `max(-u,0)`, where `u = x[d]/scale[d]` is within `[-1,1]`. At `|u| = 0.5`, normalized readout standard deviation is `sqrt(0.25/(m/2))`: about 0.06455 at the current `m=120`. This sampler loses fidelity as the population shrinks. Graded intensities, temporal averaging and context-selective activation have different behavior; this calculation is not an SNN result.

## SNN-02 — Phase, time and state representation

`Inactive | Predictive(Strength) | Active(Strength)` is illustrative semantic notation. First decide what instant each state describes. A cell active now may also participate in a prediction for a later instant, so an exclusive three-way tag needs an explicit update schedule or separate current/next state. Numenta's [reference Temporal Memory implementation](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) keeps active cells and active segments separately.

Decide whether “FP4” means standard floating-point values or a custom four-bit phase/intensity code. Standard E2M1 encodes `{0, ±0.5, ±1, ±1.5, ±2, ±3, ±4, ±6}` with signed zero; it has no independent phase tag. A custom 16-code mapping needs decoding and transition rules. Alternatively, keep phase separately from numeric magnitude. Scaling and accumulation precision remain additional choices. [NVIDIA FP4 description](https://research.nvidia.com/labs/eai/blogs/pushing-intelligence-to-4-bit/).

H-73 also permits FP16 and FP32 state; four bits are not a required state-width ceiling. H-75 proposes [two alternating frames with incoming gather](RateDynamics.md#two-alternating-frames-with-incoming-gather). Each destination is computed from the preceding snapshot, then the completed next frame becomes current. Two FP32 scalar frames cost 4.6875 MiB at the current population; connections remain single. H-77 specifies population-wide net cancellation with proportional retention; predictive phase handling, state meaning and frame duration still require discussion. A snapshot eliminates traversal-order dependence and persistent per-edge accumulation, while each destination still needs an ordinary temporary incoming sum.

H-78 deliberately keeps one activity value with predictive/active ranges and readiness distinct from current firing available for future comparison. The current design selects neither representation. Its common behavioral requirements should permit a meaningful comparison without prescribing extra state, an experiment framework or a final phase layout now.

[RateDynamics](RateDynamics.md) examines individual-neuron rate activity and fractional recruitment while retaining learned identities. Expected rate, realized binned count, selection fraction and prediction are distinct candidate meanings. Fractional selection and rate can define an effective contribution, but do not require two stored fields if only their product matters. Natural loss of propagation retains weights. Storage format, accumulation precision, rounding and the ability to represent weak decay must be designed together.

Specify whether predictive activity is emitted as current activation, as a separate prediction, or only changes future responsiveness. Membrane integration, refractory state, permanence and learning traces, if used, must each have an explicit storage or derivation rule. Four-bit cell state alone does not specify those dynamics.

## SNN-03 — Input encoding and steady recurrence

The [activation-regime contract under discussion](ActivationRegimes.md) defines the intended behavior. **Within each CC**, the active-neuron fraction stays within a broad permitted envelope; different mental states may have different characteristic fractions and fluctuations. No narrow set point, equal phase occupancy or separate whole-network activity constraint is required. With consistent counting and observation windows, whole-network occupancy is a neuron-count-weighted average of the CC occupancies and inherits their bounds.

H-59 / AD-053 requires every intended normal state to remain steerable by external token input. Autonomous recurrence is expected; stale means that no external token input can break or redirect it. This is a separate responsiveness property from activity regulation and the DMN/immersion/flow classifier. [External steerability](ActivationRegimes.md#external-steerability-stale-states-and-recovery) tracks admissible inputs, effective response criteria and a possible system-reset recovery operation whose trigger, scope and retained state remain undecided.

The three goals are no-task DMN with noise-supported recurrence and a slight negative-semantic bias producing gradual negative drift; task flow with sequential token-associated activation; and immersion with autonomous multidimensional semantic loops of varying bounded length. H-52 makes their steady attractor behavior and appropriate convergence from varied entry conditions the primary connection-learning objective. Regime-level convergence permits ongoing semantic circulation, rather than requiring one fixed neuron state. These are application goals, not claims of biological equivalence or selected learning algorithms.

An intermediate objective applies to every token: one presentation determined by semantic-coordinate strengths and H-76 prediction-guided cell selection evokes self-recurrent activity that gradually fades under low noise and returns toward DMN. H-67 permits a loose half-life-like scale around 0.5 seconds with expected token variation; it does not require completed return at that time. H-76 directs the token toward sufficiently represented predictive cells at high strength, or toward a broad minicolumn population at low strength otherwise. The exact threshold and rate calibration remain open. H-84 identifies broad weak activation as an explicit generation-mode fallback that is not learned through ordinary connections; it is not a flow teaching pattern. H-53 requires substantial global background-noise suppression when external conditions demand attention; after DMN detection, white noise increases to maintain activity and DMN slowly converges toward negative semantic content. Return does not mean silence or completion of that slow convergence. The timing concerns the token-specific response envelope; its measurement, tail criterion, cycle period, input rate and immersion lifetime remain distinct. [Activation regimes](ActivationRegimes.md#intermediate-objective-for-every-token) tracks the exact encoder, detector, control scope, observables and timing tolerance that remain open.

H-56 separates detection from regulation. Total active fraction controls activity support but does not classify the regime. Over a flexible window, DMN covers most neurons (over80% is illustrative), immersion stays within a small subset, and task flow follows a path through groups within limited short-window coverage. H-57 rules out flow above an illustrative20% coverage cap; H-58 requires discounting incidental white-noise activity, proposing a per-neuron density gate. [Activation regimes](ActivationRegimes.md#regime-detection-and-training-observables) tracks the distinct temporal coverage observable, overlap between these conditions and the remaining window/trajectory definitions.

The [synaptic integration assessment](SynapticIntegrationResearch.md) records H-22: a large input set needs an explicit integration and activity-control contract. Anatomy permits many contacts, but does not justify a flat unnormalized sum or an incoming-degree firing rule. Point-neuron gain/threshold regulation and branch-based coincidence processing are comparison candidates. Storage-only migration must preserve the transition for unchanged live edges.

H-54/H-55 add a context-dependent target: from a relatively negative-semantic DMN state, a complementary positive token produces cancellation and a short activity reduction. The activity-regulation mechanism then raises background noise before DMN detection if necessary. The small positive-semantic residual should strengthen preferentially, reach a peak and then follow token-like fading back to DMN. This specifies a desired trajectory. The active cancellation law is H-77; the recurrent response, noise-feedback algorithm and ordering of operations remain open. The activity fraction has a flexible target, and semantic content requires a separate observable.

The [physical-distance assessment](PhysicalDistancePreferenceResearch.md) starts from the existing semantic arrangement, which supplies no physical distance. Biological contact and locality findings are references for investigating useful computational effects; they do not justify adding a soft distance prior, positions or an abstract contact graph. Any proposed effect must serve the three regime goals without inventing nearness between embedding dimensions. Live degree, allocated capacity and temporal ordering remain separate questions.

- Define how signed magnitude determines external drive while context determines cell selection. Normalizing probabilities to sum to one can discard magnitude.
- Quantify the broad per-CC active-fraction envelope and regime-specific behavior, without forcing identical occupancies. HTM sequence prediction alone does not establish the required autonomous loops; bounded occupancy alone does not establish the required semantic trajectory.
- Specify thresholds, leak/integration, reset, burst behavior, intrinsic polarity cancellation, prediction timing and recurrent feedback within the early scope without explicit inhibitory connections. Decide wall-clock scheduling separately from simulated time. H-75 proposes two alternating state frames for incoming gather; the frame transition remains distinct from its neural equation. A more elaborate execution method requires a demonstrated need.
- Determine which distinctions survive scalar readout. Two different contextual cell patterns can produce the same vector; exchanging only that vector can intentionally discard context, but the choice must be explicit.
- Future evidence should cover the per-CC activity envelope, regime-dependent occupancy and convergence, token-specific recurrence, loose half-life-like decay and timely fading, signed fidelity, saturation, repeated encode/decode drift, sequence-context discrimination and response to changing drive. Exact tolerances and experimental protocols remain open.

## SNN-05 — Embeddings, messages and learning

H-71 includes useful noise-supported small loops as a way for longer context to influence later network output. Main-chain construction should avoid deliberately harmful shortcuts, while preserving useful recurrence. [ContextLoopsAndNumerics](ContextLoopsAndNumerics.md) examines this behavior together with accumulated/scheduled decay and field-specific integer representations; dominant token fading does not imply complete erasure of prior-input influence.

The current embedding discussion uses DeepSeek-V4.1-Flash. The official [launch configuration](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/raw/main/config.json) and [1017 configuration](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/raw/main/config.json), checked 2026-10-26, both give `text_config.hidden_size=5120`, `vocab_size=129280` and untied input/output embeddings. The official [inference implementation](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/raw/main/inference/model.py) constructs the main token embedding with vocabulary × dim; its later hyperconnection copies do not multiply the input embedding width. This calculation uses the native 5,120-dimensional token vector.

The [Flash-1017 input-table measurement](TokenEmbeddingStatistics.md) pins revision `1bae0e1088993b9b82de08f59de5be5a34e42170` and extracts `embed.weight`, BF16 `[129280,5120]`, to the local SSD. Its source-shard checksum matches. All 127,997 ordinary BPE types have 5,120 nonzero coordinates; median top-coordinate energy is 0.283%, and median 90%-energy coverage requires 2,278 coordinates. Coordinates are distributed but not statistically identical or independent. This is input-table evidence, not SNN activation statistics or a final deployment/encoding choice. Tokenizer, normalization and SNN learning must use the same selected embedding schema. Contextual transformer computation and CC recurrent weights remain separate.

Pin tokenizer, checkpoint, tensor, scaling and saturation together. Define whether packets carry continuous vectors, token IDs or both: a recurrent state need not coincide with a vocabulary token. Output-to-token decoding is a separate design; even an available pretrained output head needs compatible state semantics.

H-28 makes the input semantic-vector table a shared node resource for the CCs using it. Its storage belongs to the node budget, separately from each CC region's connection and state arrays. The sharing mechanism is not selected by this accounting boundary.

H-63 proposes unified DMN/token chain construction and ongoing repair: deficient next-step activation leads to selection from the eligible neurons that should activate but have not. [TrainingStrategy](TrainingStrategy.md#unified-next-step-repair) separates the expected response, naturally achieved response, selected repair group and durable connection update. H-62's fixed groups remain a possible reference; no final target or overlap policy is selected. H-79 retains Hebbian/HTM as the direction for flow learning on token sequences. Its algorithm is not established; H-80/H-81 require a separate initial design and early discussion of open decisions. H-82 sets matching predictive preactivation as the direct training criterion; self-sustaining continuous generation is a separate design problem. Immersion remains an emergence without dedicated training.

H-64 adds whole-chain consideration to stepwise sampling: quantity goals must coexist with intended progression and avoidance of premature return. The [global-constraint analysis](TrainingStrategy.md#global-constraints-and-stepwise-sampling) distinguishes previous participant roles, explicit closure permissions, future eligible-cell availability and indirect paths through existing connections. Excluding earlier targets does not alone guarantee the absence of effective shortcuts. A permanent global phase per neuron, new runtime role field or universal prohibition of cycles is not selected.

H-65 fixes the concrete participating scope once per maintenance epoch: all CC neurons for DMN, or minicolumn cells selected in token-vector proportions for a token. Stepwise selection operates within that scope. Approximate width gives a rough pass length of scope size divided by width; body enhancement and tail/head attenuation are goal-dependent strategy parameters. The intended return wiring remains connected under H-66; token-response duration spans recurrent activity and does not specify one lap. H-66 also prefers preserving token proportions in each step, with at most a few steps of bounded deviation. [TrainingStrategy](TrainingStrategy.md#per-step-targets-and-bounded-short-window-deviation) separates original-vector targets, integer epoch counts, complete next-step participation and actual activation strength. Width, finite per-population counts, return gain and the allowed semantic window must be considered together. The selection does not reset retained connectivity or require cells outside the target scope to be silent.

H-43 fixes the semantic assignments within which construction and learning operate. H-61 accepts omitting physical-distance preference at this stage; H-41's dimension neutrality and H-42's rejection of cross-minicolumn internal-position bias remain. The required behavior includes regime attraction, finite token responses and external steerability. Concrete group quotas, neuron transitions, gains, overlap policy and flow-learning updates remain open. Direct construction does not by itself guarantee those dynamical properties.

Under H-24, weight scale belongs to training strategy: it may be considered as a hyperparameter or planned/adapted dynamically. Capacity allocation supplies storage for the learned graph; it does not prescribe the scale. The [training discussion](SynapticIntegrationResearch.md#training-strategy-incoming-weight-scale) keeps the rule, objective and any extra state open.

## SNN-06 — Regions, persistence and language requirements

The resident CC region owns its model/state. A message region can carry an activation vector without copying the complete connectivity structure. Native execution resources need explicit lifetimes outside persistent process-local addresses. Regional references retain the repository's zero-cost relocation and region-lifetime requirements; no layout is selected here.

Decide what DBMR retains: definitions, learned connectivity, checkpoints, selected observations or every update. Runtime mutation, append-only history and backing-file compaction require separate policies; no per-tick durable logging requirement is inferred. The static live connection pool can change assignment without generating historical versions. If old states are retained, their history and compaction workspace have separate capacity budgets; a live set selected for reuse cannot itself serve as immutable history.

Candidate language requirements include phase sums, structured CC state, bounded arrays, signed vectors and methods to receive input, advance state and read out results. Their effects, ordering, random-number semantics and precision must first be specified in this application document set; reusable requirements can then enter the CoD language tracker. Application decisions do not implicitly change CoD's language or storage contracts.
