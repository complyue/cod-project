## Flow learning: initial design scope

Flow training learns from externally supplied token sequences in the Hebbian/HTM direction specified by H-79. Its algorithm is an open design task under H-80/H-81. The [DMN/isolated-token repair process](TrainingStrategy.md#unified-next-step-repair) supplies neither its default update rule nor its target-selection procedure. Common neuron dynamics, incoming-slot storage and numerical operations can still be shared without equating the learning methods.

H-82 specifies the direct ideal result: predictively preactivated neuron populations closely match the input sequence. Preactivation may be too weak to sustain autonomous continuation; close matching is sufficient as the direct learning criterion. The mechanism and algorithm for continuous output generation are a separate design task. This does not select a prediction metric, threshold, loss, weight update or readiness representation; H-78's state comparison remains open.

A proposed assessment should inspect the prediction before the incoming token changes the state. Comparing prediction only with the neurons that H-76 subsequently selects from that prediction would risk a self-confirming score. The comparison needs an independent incoming-token criterion and a way to expose irrelevant predictions, while permitting different contextual cell identities for the same semantic component. Exact matching/coverage measures remain discussion points.

H-83 makes validation depend on sequence context: several predictions are expected while a matching fragment is compatible with several sequences; as the observed sequence grows, predictive diversity should contract toward the training sequence. This is a trajectory of increasing specificity, not a requirement to choose one continuation at every input. An alternative not selected by one arriving token is therefore not automatically an invalid association.

The measure of diversity must concern distinguishable plausible continuations. Raw predictive-cell count or entropy over semantic coordinates is not automatically that measure: one dense graded token can involve many coordinates and cells, while alternatives can share them. A proposed assessment can use known overlapping training sequences and examine compatibility before each new input, without selecting a generation decoder. Narrowing should be checked where the available context distinguishes continuations; identical observed histories cannot identify an unobserved future branch. No strict frame-by-frame monotonicity, entropy formula, candidate store or weakening policy is selected.

Low predictive strength and no useful prediction are distinct. H-82 removes the requirement that readiness drive a self-sustaining output sequence; it does not define numerical dust or an indiscriminate predictive population as a successful match. The eventual readiness semantics and input-compatibility measure must make that distinction without requiring the amplitude of an active generated token.

Before choosing updates, distinguish preceding context, naturally transmitted predictive readiness, the observed training token and the connection changes credited to that observation. The H-75 two-frame boundary provides a consistent observation point; it does not select an eligibility trace, stored token history or Hebbian timing window. Flow credit rules must be defined independently of the generation fallback described below. This remains a separate learning design from DMN/token missing-group repair.

### Provisional flow procedure for comparison

The following procedure makes the causal roles concrete enough to compare. It is a proposal within C-15/P-29, with its choices exposed; it is not an implementation contract. Use an observed training token as the reference learning exposure. A time-integrated alternative can then be compared without accidentally counting the same observation once per neural frame.

| Step | Candidate operation and purpose |
| --- | --- |
| Inspect the preceding state | Use a completed frame to assess natural prediction before the observation changes activity or weights. Extract the preceding source credit `c_i` under the chosen activity/readiness interpretation. |
| Assign the observation | Map the observed signed vector to its fixed coordinate/polarity populations. Assign learning responsibility `y_j` using preceding contextual compatibility; reuse meaningful matches, and provide a randomized no-match entry within the permitted semantic population. Assignment must be independent of generation fallback. |
| Establish the next context | Compare responsibility-only assignment with an independently defined input intervention on those selected cells. The latter is a training input, not evidence of a natural prediction. It must explain what happens to ongoing contextual activity rather than silently replacing the whole CC state. |
| Adapt retained associations | Apply one explicitly defined correlation/weakening rule to the eligible source/target pairs. Specify whether nonselected targets or inactive sources are included; that exposure set changes what the weights learn. |
| Discover absent sources | Where growth is justified, a simple candidate samples from the credited preceding sources, weighted by their credit and excluding already represented IDs. Growth amount and capacity admission remain comparison choices; insufficient capacity is not repaired by changing semantic roles. |
| Publish and assess | Finish reads that require the previous weights before publishing changes at a consistent boundary. Assess later pre-input matching, contextual narrowing and preserved shared recurrence using the stored numerical weights. |

Here `c_i` and `y_j` name roles in the calculation, not additional persistent arrays. The source interpretation must distinguish an observed context from an unchosen prediction; a complete neural frame is not automatically the last token's representation. The incoming graph is the first available source of contextual compatibility. Raw weighted drive and a suitably normalized score are comparison options, since degree and scale affect raw drive; no score formula or new matching field is presumed. Capacity can establish feasibility, but cannot prove contextual compatibility.

This procedure learns correlations associated with observed sequence transitions. It does not compute DMN/token next-group shortfalls or select missing chain members to repair a prescribed activation lap. The training-state intervention remains paired with the responsibility-only alternative until actual sequence behavior distinguishes them. The no-match entry must allow unfamiliar transitions to become learnable, while repeated matching contexts should reuse useful distinctions rather than be randomly reassigned on every exposure.

### Assessing contextual prediction on actual sequences

H-86 leaves empirical choices to controlled comparisons. A candidate assessment should separate four claims: compatibility with the observed token, retention of context through shared fragments, representation of legitimate alternatives, and improvement attributable to learning. No single aggregate activity or vector-direction score establishes all four. [Conditional prediction arithmetic](../research/flow-prediction-assessment-analysis.json) supplies examples, not measured SNN performance.

Compare the same pre-input forecast positions against a token-frequency or shorter-context reference. A positive association can reflect a frequent target without carrying additional context: under independent source and target events, the source-enabled update discussed below approaches the target's marginal frequency. That is not itself an error, but it does not demonstrate contextual discrimination. Genuine histories sharing a recent suffix and differing in informative earlier context make that distinction observable. Arbitrarily shuffled histories can instead introduce unfamiliar inputs, so they answer a different question.

Preserving ambiguity can improve prediction without choosing one continuation. In an illustrative equal mixture of two histories whose next-token distributions are `(0.75,0.25)` and `(0.25,0.75)`, the shorter-context marginal is `(0.5,0.5)`. Correct contextual probabilities reduce expected logarithmic loss from 1 to about 0.811 bits while both histories remain ambiguous. These probabilities and scores are a reference calculation; readiness and weights have no adopted probabilistic interpretation.

If an assessment later defines token probabilities, a proper probability score can distinguish faithful ambiguity from unwarranted confidence. For a true `(0.9,0.1)` distribution, forecasts `(0.9,0.1)` and `(0.99,0.01)` both have 90% top-one success, but the latter has worse expected Brier and logarithmic losses. Simply rewarding the probability assigned to the observed event favors excessive confidence in this example. [Gneiting and Raftery (2007), §§2.3–3.1](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf) distinguish proper scoring, categorical scores and comparison with a reference. This does not prescribe a probability decoder, a loss for training, or a scalar acceptance threshold.

A good semantic point prediction need not preserve alternative tokens. For equiprobable vectors `(1,0)` and `(0,1)`, their mean `(0.5,0.5)` minimizes expected squared vector error. More generally, a linear readout of 5,120 coordinate means cannot uniquely recover an arbitrary probability mixture over 127,997 ordinary token types: the augmented embedding-and-normalization map has a null space of dimension at least 122,876. This is a dimensional bound, not a measured rank or a failure of individual token embeddings. Full contextual neuron patterns can carry distinctions absent from their coordinate means. A comparison should state what its readout can establish; it need not implement the separate generation mechanism.

Nor is narrowing a monotonic entropy requirement along every stream. Conditioning on more information about the **same** future token reduces average conditional entropy, but a particular revealed history can increase it. Moving to the next token also changes the prediction target. Assess H-83 on shared and distinguishing sequence fragments, without demanding knowledge of an unresolved future branch. Finite observed branches provide evidence about plausibility, not proof that every unobserved branch is impossible.

[Asabuki and Clopath (2025)](https://elifesciences.org/articles/95243) learn first-order stochastic transitions in an E/I recurrent model. Their predictive poststimulus result averages across trials that can visit different assemblies. Such average compatibility does not establish multiple alternatives available within one particular pre-input state. The authors also identify higher-order and temporally separated transitions as limitations. Their inhibitory plasticity, adapted response functions and spontaneous-replay objective are not adopted; our comparison must state whether ambiguity is represented within a state or only across repeated outcomes.

| Comparison | Evidence it can supply | Boundary |
| --- | --- | --- |
| Learned sequences, updates held fixed during assessment | Retention of acquired contextual prediction without contemporaneous teaching | Not automatically generalization to new occurrences |
| Whole held-out sequences or episodes, with any assessment mapping fitted only on training data | Generalization across occurrences and histories | A stronger separate claim; not an added H-82 threshold |
| Sequential prediction followed by the declared learning update | Value of continuing adaptation | Earlier assessed observations become training history |
| Genuine shared suffixes with informative earlier histories | Contextual improvement beyond the recent fragment | Use the same forecast positions and record actual ambiguity |

[Dawid's prequential formulation](https://people.csail.mit.edu/jrennie/trg/papers/dawid-prequential-84.pdf), introduction and §3, provides the prediction-then-observation ordering; its probability-forecast model is not assumed for neuronal readiness. For each comparison, distinguish the starting state and prior exposure, actual token timing, noise conditions and any independent training intervention. A richer assessment mapping must not obtain the missing history or future label from outside the neuron state and thereby claim that the network retained it.

A fitted readout can reveal information without establishing natural predictive readiness. Two histories can leave distinct state patterns while next-token readiness remains identical; a supervised probe can decode their continuations without improving that readiness. [SORN (Lazar, Pipa and Triesch, 2009)](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/neuro.10.023.2009/full) evaluates separately trained readouts and reports that representational drift can require retraining. A diagnostic comparison must state whether its mapping stays fixed during further learning.

[Rule et al. (2020)](https://elifesciences.org/articles/51121) analyze mouse posterior-parietal recordings across days. Single-day decoders degrade, while fitted multi-day or adaptive decoders can retain useful task information. Their adaptive linear readout receives kinematic target-error feedback; this is not measured biological synaptic compensation or natural next-token readiness. Offline analyses also restrict trials and center signals. The result supports examining downstream use alongside changing representations, without requiring frozen cell meanings. It neither calibrates our within-episode context lifetime nor selects a compensating learner. Readiness layout under H-78 remains a separate choice.

[Rule and O’Leary (2022)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8851551/) show simulated maintenance without external error feedback after an initial readout has been learned. Redundant tuning and per-cell mean/variance regulation support that result; stronger variants use stable recurrent structure. This supports comparing retention during contextual reuse, not treating self-reinforcement as acquisition of unfamiliar token transitions. Their per-cell regulation is also different from our per-CC active-fraction controller. Neither the controller nor high activity alone establishes preserved associations.

Robustness within one input pattern differs from retaining context through a changed sequence element. In [Cui, Ahmad and Hawkins (2016), draft v2 §§4.5/6.4](https://arxiv.org/pdf/1512.05463v2), replacing an internal symbol can remove HTM's higher-order advantage despite its sparse-pattern robustness. That intervention is not our background rate noise. The authors also limit their demonstrated tasks to categorical or scalar streams. These results support keeping pattern perturbation, an unexpected token and ongoing background fluctuations distinct when comparing retained context; they do not select a recovery policy, hierarchy, history buffer or a new robustness requirement.

Dataset record order is not automatically sequence order. Credit a record-end-to-next-record transition only when that join is deliberately supplied as a sequence. The starting-state protocol for a learning comparison is separate from normal recurrent dynamics and from recovery of an externally unsteerable state. No reset procedure, delimiter token, history buffer, candidate store or generic experiment framework follows from these assessment requirements.

Whole-sequence averages can conceal the required context effect. In the [conditional shared-fragment example](../research/flow-context-assignment-analysis.json), `A,X^k` and `F,X^k` require different final tokens. A predictor that gets the `k` shared transitions right but guesses the final branch achieves `1-0.5/(k+1)` mean accuracy: about 97.62% for `k=20` and 99.50% for `k=100`. Branch accuracy remains 50%. Compare those distinguishing positions as well as ordinary shared transitions; this selects neither a universal score nor a runtime branch detector.

### Generation fallback and sequence learning

H-84 specifies that broad weak activation is a generation-mode behavior implemented explicitly, rather than produced through ordinary neuronal connections, and is not learned. It is neither a flow teaching pattern nor a population from which the flow learner chooses strengthening recipients. The observed input sequence still supplies the prediction-matching criterion; how unfamiliar transitions establish a learning representation and new associations remains to be designed independently.

Numenta's [reference implementation](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) distinguishes active cells from learning winners: an unexpected column can activate broadly while selecting one winner. With learning enabled, segment adaptation uses previous active cells, whereas new synapses are drawn from previous winners. Those are distinct roles and operations. H-84 defines our generation fallback's exclusion from learning; importing the reference learning path would not establish that exclusion automatically.

The useful design question is how to represent an observed training token in its preceding context and learn associations that improve later preactivation. It is not how to learn the artificially supplied broad generation response. No winner array, dendritic segment, permanence field, training stimulation rule or cold-start algorithm is selected by this distinction.

Useful context, external steerability, activity regulation and preservation of required DMN/token behavior constrain the eventual flow learner. The detailed learner, its interaction with construction/repair, and whether training occurs only at token events or across an interval remain open. Findings that bear on these choices should be discussed before selecting mechanisms.

### Learning an unfamiliar transition

A learner that strengthens associations only after an already successful prediction has no positive update for an entirely unpredicted transition, unless another learning path supplies it. This is a conditional observation about that rule, not a claim that the existing network lacks useful partial context matches. H-84 leaves unfamiliar-transition learning open while excluding the explicit generation fallback from its teaching basis.

A first candidate for discussion is to assign learning responsibility using the observed token and preceding context: reuse a compatible contextual response when available, examine meaningful subthreshold input when prediction is insufficient, and specify an assignment rule for the no-match case. The existing incoming graph is the first information source to examine. Its weighted input is not automatically an adequate similarity measure; activity, weight scale, degree and [weight concentration/source covariance](SynapticIntegrationResearch.md#why-the-simple-sum-needs-a-degree-aware-specification) affect it. No matching array, neuron quota, dendritic segment or assignment rule is selected.

HTM's weak match has a particular meaning. The [NuPIC connection calculation](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/connections.py) counts every retained synapse from an active source as potential activity, while connected activity additionally requires a permanence threshold. The [TemporalMemory reference](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) can reuse a matching segment with the largest potential count before it produces a strong prediction; without a match it chooses a cell with fewest segments, breaking ties randomly. Permanence therefore controls binary connectivity in this calculation, rather than multiplying a graded source rate. Our small effective weight need not mean an uncertain association. Renaming it permanence would not preserve the proposed incoming weighted sum. Compare contextual compatibility and natural transmitted readiness as distinct observations, using existing state and edges first. Dense graded input also leaves any binary activity cutoff to be justified. This reference does not select a second confidence field, segment structure, least-used-cell policy or burst-based teaching; H-84's fallback exclusion remains.

The [conditional two-context example](../research/flow-context-assignment-analysis.json) shows why semantic correctness alone does not determine that assignment. Two cells in the same coordinate/polarity population can represent the same total semantic value while distinguishing two histories. A learning rule that repeatedly assigns the same mixture to both histories loses that distinction in the illustrated transition. Other recurrent state can still retain context, and distributed use of sixty cells does not imply a limit of sixty tokens or global contexts.

[Context selectivity](SynapticIntegrationResearch.md#context-selectivity-is-separate-from-connection-capacity) also depends on integration. More incoming slots do not make one weighted-sum detector recognize arbitrary alternatives of source conjunctions. Existing contextual cells, the chosen nonlinear recurrent transition and separate input groups are different ways to supply that computation, with different costs. Favor an additional mechanism only when actual shared or mixed contexts expose a prediction deficit that the simpler candidate cannot adequately resolve. Random sparse-pattern bounds alone do not establish selectivity for repeated dense semantic inputs.

Two candidate operations require comparison:

| Operation | What it supplies | What still needs evidence |
| --- | --- | --- |
| Assign learning responsibility only | A context/observation-based target for changing associations. | Ordinary training dynamics must still produce the contextual state that will support learning the following transition. Assigning credit does not itself activate the selected cells. |
| Establish an observation-conditioned training state | An explicit contextual representation of the observed token, with preceding associations trained toward it. | The intervention must be defined independently of generation fallback, and natural pre-input prediction must succeed without counting the assistance as evidence. |

Neither operation is selected. They are flow-learning candidates grounded in observed sequences, not imports of the DMN/token missing-group repair rule. A subsequent update must identify responsible preceding activity and preserve required shared recurrence; simply naming Hebbian reinforcement does not settle weakening, bounds, timing, source eligibility or precision. Additional metadata and separate connection classes do not follow from these questions.

### Contextual assignment and natural readiness

A learning selector and the neuronal transfer need not rank cells identically. In the [conditional score examples](../research/flow-context-assignment-analysis.json), source activity `(1,0)` supplies drive 1 to a row `(1,1)` and 0.6 to `(0.6,0)`. Raw drive favors the first; cosine or normalization by total row weight favors the second. Reducing the second row to `(0.06,0)` preserves its normalized match but reduces its transmitted drive tenfold. Shape matching can identify a useful partial association, but cannot by itself establish that the cell naturally predicts. An empty row has no defined cosine; assigning it a contextual role needs an explicit no-match policy.

Exact symmetry is another conditional limit. If exchanging two contextual cells preserves the complete relevant state, connections, input and deterministic update rule, that exchange symmetry persists. The rule cannot distinguish those cells by the missing information. Existing graph and state differences can already break this symmetry; no extra random field or artificial neuronal coordinates follow. Conversely, breaking a tie once does not establish context specificity: always favoring the same index can give different histories the same recipient. Reuse must be judged by subsequent prediction on those histories.

Reserved capacity does not measure contextual compatibility. Dividing drive by capacity can reverse the recipient ranking after a storage-only migration: drives 0.8 and 0.7 divided by two 100-slot capacities favor the first; moving only its unchanged effective row to 144 slots favors the second. Such a policy would make provisioning affect learning despite unchanged inputs and weights. Distinguish that policy from normalizing effective incoming weights, which also has behavioral consequences and remains a comparison option.

Selecting learning responsibility after observing a token does not itself suppress other pre-input predictions. Nor does a computational selection of learning recipients introduce modeled inhibitory connections. Keep these roles distinct from generation fallback, active cancellation and natural neuronal competition. Compare simple drive-based selection with contextual shape matching where they differ: unfamiliar-transition acquisition, repeatable reuse, discrimination after shared fragments, retained legitimate alternatives, natural pre-input matching and slot demand are the useful observations. Neither a normalized score nor a small recipient group is selected; extra matching statistics or a winner array require demonstrated need.

### Contextual reuse must preserve predictive distinctions

A repeatable or well-matched representation is not necessarily predictive. A [four-pattern calculation](../research/flow-context-assignment-analysis.json) uses source patterns `(c/4,n)`, where `c` and `n` are independent fair bits and the continuation depends on `c`. Of all two-group partitions, grouping by the stronger but irrelevant `n` minimizes squared input-reconstruction error at `1/64`; its group identity predicts the continuation only at chance. Grouping by `c` has larger reconstruction error `1/4` but predicts perfectly. This concerns the selected representation alone: other retained neural state can still carry `c`. It does not prescribe clustering, two recipients or a new semantic axis.

[Nessler et al. (2013)](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003037) give an explicit input-distribution fitting interpretation for a particular STDP/WTA system. Its categorical encoding, exponential firing, inhibitory competition and intrinsic plasticity support that result. This does not establish that an arbitrary Hebbian rule or contextual similarity score optimizes continuation prediction in our fixed semantic populations.

[Klampfl and Maass (2013)](https://igi-web.tugraz.at/PDF/218.pdf) find context-specific assemblies in recurrent WTA circuits, but report instability when an identical input persists across contexts. Their learned assemblies also change processing of novel inputs. These results support comparing retained contextual discrimination and flexibility alongside familiar-pattern reuse; their spatial wiring, inhibition and plasticity are not adopted.

Contextual identity need not distinguish every past occurrence. Reuse is useful when it preserves the distinctions needed for later preactivation and behavior. Conversely, identical current tokens or identical immediate next tokens do not establish that two histories are interchangeable further along the sequence. Assess actual shared and distinguishing continuations at increasing lengths; no fixed history buffer or one-cell-per-history rule follows.

Reassignment can preserve information while disrupting its learned use. In an [exact two-cell reference](../research/flow-context-assignment-analysis.json), both cells have the same coordinate/polarity role, but distinguish two histories and drive different subsequent targets. Swapping their history assignments preserves the current semantic sum and distinguishability; unchanged downstream weights now interchange the predictions. Refitting a diagnostic readout could hide this failure of natural readiness. This does not forbid reassignment or require global remapping: assess its later behavioral effects and any recovery through learning. Capacity-only set migration is different: it preserves cell IDs and effective connections. With incoming ownership, a cell's downstream references reside in other targets' sets, so changing its own row does not automatically compensate their learned use.

[Martinez, Lansner and Herman (2019)](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0220161) use offline batch learning from prescribed input time series for their sequence-recall experiments. Their graded internal currents and adaptation feed binary winner-selected outputs. They distinguish partly overlapping pattern recall from disambiguating identical shared patterns; noise can improve a limited disambiguation case by accelerating traversal before context fades. This motivates checking elapsed model time as well as observed sequence length: faster traversal does not establish longer-lived memory. The reported recall does not verify an online learner or graded semantic-cell output. Their competition, adaptation, traces and signed weights remain unselected; autonomous recall is not H-82's flow criterion.

### Contextual selectivity within fixed semantic roles

A cell's fixed coordinate/polarity contribution does not require its response to depend only on that coordinate's current input. H-75 already gives individual cells distinct contextual paths. Their existing incoming connections and response law can, in principle, make the same semantic population respond differently to combinations of earlier activity. Whether the proposed learning rule develops the needed distinctions remains a behavioral question.

[Rigotti et al. (2013)](https://www.nature.com/articles/nature12160) analyze 237 prefrontal neurons recorded in two monkeys during an object-sequence task. Their population analysis relates nonlinear combinations of task factors to accessible classifications; error trials show reduced dimensionality even though individual cue identities remain decodable. This supports examining contextual combinations beyond current-token identity. It supplies neither an anatomical identification with our minicolumns nor a learning rule for fixed signed populations. The main-text analysis uses pseudo-populations and resampling; the supplementary methods have not been independently checked here.

[Barak, Rigotti and Fusi (2013)](https://barak.net.technion.ac.il/files/2012/10/barak_rigotti_fusi_2013.pdf) show a discrimination/robustness trade-off in a specified random intermediate-layer model: sparse responses can resist noisy input variations, while overly sparse finite populations lose distinctions. Their approximately 10% optimum belongs to binary inputs, particular noise, signed random projections and a trained linear readout. They also vary intermediate population size across noise conditions. It does not set this CC's flexible activity envelope or choose a quota within its sixty-cell populations.

For our comparison, hold the existing cell budget and semantic roles fixed. Check both separation of histories requiring different continuations and repeatable prediction from the same history under the intended background conditions. Greater response diversity or rank is useful only when it improves those outcomes. A noisy cell pattern can be highly diverse without carrying predictive context; identical present semantic sums can still hide useful individual-cell distinctions. Evaluate these effects through subsequent preactivation before adding a hidden layer, dendritic subdivisions, a diversity objective or any extra state. This is a comparison within the existing design space, not an additional training goal.

Additional history is not necessarily additional activity in every source cell. Under fixed nonnegative weights and a coordinatewise nondecreasing response, a componentwise increase of the source pattern cannot reduce any target response. A fixed-threshold ready set therefore cannot narrow through that operation alone. An [exact two-source example](../research/flow-context-assignment-analysis.json) contrasts adding activity with changing the participating identities; the latter can remove one prediction while retaining another. This does not prove our complete model monotone: cancellation, changing context composition and background regulation fall outside those assumptions. A relative ranking can also change without reducing absolute readiness. Check the actual pre-input populations as distinguishing context arrives, without inferring new inhibition, competition or a state-replacement policy. H-85 still leaves predictive cancellation open.

### Signed population overlap and contextual specificity

Splitting a vector into its nonnegative polarity contributions changes a simple overlap score. Define `phi(v)=(max(v,0),max(-v,0))` coordinatewise. Then:

```text
||phi(v)|| = ||v||
phi(v) · phi(w) = (v · w + |v| · |w|) / 2
```

The [read-only Flash embedding probe](../research/signed-population-overlap-probe.json) samples 1,024 ordinary token types and 4,096 distinct-type pairs from the existing SSD tensor. For unit-normalized rows, median signed cosine is about **0.0439**, while median polarity-split nonnegative cosine is about **0.3408**. Among 2,355 sampled pairs with signed cosine between −0.05 and 0.05, median split overlap is about **0.3314**. This is type-sampled arithmetic, not corpus-weighted semantic labels or measured neural responses. Actual contextual selection among sixty cells can change cell-level overlap; the probe does not prescribe a uniform encoder.

A restricted positive outer-product reference makes the consequence explicit. For unit source contexts `x_a` and target patterns `y_a`, let `W=sum_a y_a*x_a^T`. Its response to `x_b` is `y_b + sum_(a!=b) y_a*(x_a·x_b)`: overlapping source patterns contribute cross-associations. This is an analysis of unspecific superposed reinforcement, not a proposed dense weight matrix or proof that the SNN fails. Contextual cell identities, nonlinear integration, signed cancellation and learning assignments affect the actual result. A high aggregate nonnegative overlap alone is insufficient evidence of predictive semantic matching; centering, inhibitory edges and extra context fields are not inferred as remedies.

Intrinsic cancellation does not automatically remove those terms. In an [exact aggregate example](../research/cancellation-recurrence-analysis.json), learning `x=(1,1)` to `y=(1,0)` through a normalized positive outer product of their split encodings gives a response `(0.5,0)` to `v=(1,-1)` even after cancellation, although `x·v=0`. A different nonnegative operator can realize the signed-linear response through opposing target populations, but that operator includes connections absent from the illustrated coactivation update. It is a capability example, not a reason to pair positive/negative cells by index or introduce mirrored connections.

More generally, an aggregate reference with nonnegative blocks `W=[[A,B],[C,D]]` gives net input `(A-C)*p+(B-D)*m` for source polarity magnitudes `p,m`. On post-cancellation aggregate sources this can depend on both the signed vector `v=p-m` and its absolute magnitude. H-77 does not enforce the balance `A+B=C+D` that would remove the absolute-magnitude term. Such dependence is not inherently wrong: this network is not required to implement a linear semantic map.

Nor should matching be repaired by erasing all information invisible to the current semantic readout. For a fixed linear neural transition `W` and readout `D`, requiring exact closure `D*W=K*D` makes equal present semantic vectors remain equal under every later unforced linear step. That excludes one route by which different contextual cell patterns influence future output. Actual nonlinear and input-dependent responses need their own assessment. The required outcome is context-sensitive prediction, not enforced aggregate linearity.

[Bouhadjar et al. (2022)](https://arxiv.org/html/2111.03456v2) report context-overlap problems with generic Hebbian growth in their spiking TM model and use dendritic-activity homeostasis to reduce them. Their limitations include repeated sequence starts and task-tuned homeostatic timing. This supplies a comparison question, not an adopted solution: their inhibition, plateau, permanence and burst-learning assumptions differ from this model and H-84.

[Bouhadjar et al. (2025)](https://juser.fz-juelich.de/record/1049039/files/article.pdf) report correct-element readiness developing before unwanted predictions resolve. Their evaluation reads internal dendritic events before each input and compares binary column predictions against that single presented symbol. This supports examining readiness independently of generated output, but its single-symbol false-positive criterion cannot simply be imported for dense semantic vectors and H-83's legitimate alternatives. Their maturity decay can also remove useful associations without renewed exposure. Acquisition, contextual specificity and retention therefore remain distinct comparisons. The categorical encoding, inhibitory competition and synaptic-maturity mechanism are not adopted.

### Causal roles in a flow-learning step

The [provisional procedure](#provisional-flow-procedure-for-comparison) separates natural pre-input prediction, observation-conditioned learning responsibility, preceding-source credit and later acquired behavior. These are conceptual roles, not additional persistent fields or a DMN/token repair loop.

Evaluation with learning updates held fixed can separate an acquired state-dependent association from further online adaptation; it is a comparison option, not a requirement to disable online learning generally.

The [NuPIC reference](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) processes an observation through `activateCells`, then computes the predictive segments for the next algorithm step. This distinction supports causal assessment; it does not equate that step with our neural frame or import burst learning. [Token/frame timing](RateDynamics.md#token-order-model-time-and-input-boundaries) explains why several observations cannot simply be combined into an unordered input while claiming the same contextual task.

For example, two histories can share the recent fragment `D,B` but require different continuations because one began with `A` and the other with `F`. Some difference must remain in the causally relevant model state for identical later inputs to yield different continuation distributions. Existing contextual cell identities and recurrence may supply it. If the complete causal state has become identical, a learner cannot reconstruct the lost distinction from `D,B` alone; identical state and future forcing give identical future behavior under the same update law. This does not require a separate history buffer or a fixed context length.

[Lober et al. (2026), preprint](https://arxiv.org/html/2605.22523v1) distinguish order learning from duration encoding and replay control. Their timing examples repeat input elements to recruit assembly sequences and supply a top-down cue to the first assembly. They use inhibitory competition, dendritic plateaus and oscillatory replay drive. These mechanisms and repeated forcing do not transfer to our isolated one-presentation token objective or become prerequisites for H-82 flow acceptance.

A supplied sequence identity, position label or expected continuation carries information beyond an otherwise ambiguous observed prefix. A real external cue can be an explicit task input; an evaluation must not silently borrow it from the training record and attribute the resulting distinction to retained context. Likewise, decoding an observed sequence position after input is a different task from predicting the next input beforehand. This boundary selects no start cue, reset or readout architecture.

The causal prediction boundary does not forbid learning from a sequence after its later observations have arrived. [Kappel et al. (2014)](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003511) distinguish online approximation from training that uses whole-sequence evidence; their improved approximation uses replay and synaptic tags. Immediate local credit and later outcome-informed credit are comparison candidates if actual shared-fragment learning exposes a difference. Any extra history or replay work needs demonstrated value. No tags, buffer, rejection sampler, hidden-state labels or retrospective learner are selected, and later training evidence cannot be counted as information available to an earlier prediction.

Under H-86, assignment and weakening choices belong in later comparisons on actual shared, repeated and disambiguating token sequences. Favor choices that learn unfamiliar transitions, retain contextual distinctions through shared fragments, and preserve legitimate alternatives until the input resolves them. An observed branch can strengthen its association without treating every unobserved alternative as erroneous. The policy, cadence and numerical precision remain open, alongside the existing preservation checks for DMN/token recurrence.

### Preceding source credit and sparse growth

An observed contextual response and an unchosen predictive alternative are different possible sources of learning credit. Suppose a context predicts both B and C, the next observation is B, and then D arrives. Crediting C's readiness as though C had been observed can strengthen C-to-D in a rule intended to associate observed contexts. This conditional example does not forbid weak activity from carrying useful history. Compare source credit based on the independently established preceding representation with graded credit from neural activity, checking both retained context and contamination from unobserved alternatives. H-78 leaves their state representation open; no winner array or eligibility trace follows.

[Recurrent emission](RateDynamics.md#what-a-frame-value-means) is a separate question from learning credit: excluding an unobserved prediction from a direct weight update does not by itself prevent that prediction from influencing the next neural state if its readiness is transmitted. Conversely, nonemitting readiness need not erase weak current firing that carries context. Compare these meanings alongside the declared source-credit rule; state layout alone selects neither.

The preceding neural frame also need not represent the preceding token when several frames occur between token events. The candidate rule must identify which information remains available when credit is assigned. Two-frame storage defines consistent state access; it does not retain an arbitrary preceding token pattern. A longer credit window needs demonstrated predictive value before its supporting state is designed. H-58's coverage filter serves regime classification and is not automatically a source-eligibility rule.

Credit magnitude alone does not identify useful context. The [conditional source-credit arithmetic](../research/flow-temporal-credit-analysis.json) considers a first draw from 307,200 eligible absent-source candidates: 6,144 informative candidates have credit one, and the rest have credit 0.01. Sampling in proportion to credit selects outside the informative group with probability **32.89%**, despite each such candidate having only one percent of the strong credit. The informative labels belong to the diagnostic example, not to a runtime selector. A shared positive target-error multiplier cancels from these relative probabilities; it can change when or how much growth occurs without identifying better sources. Later draws depend on the exclusion and replacement rules.

The same artifact examines the source-enabled affinity update `w += eta*c*(y-w)` under independent fixed-role exposures and exact arithmetic. If an informative preceding indicator perfectly predicts a binary target of frequency `pi`, but has credit one when present and 0.01 otherwise, its stationary mean weight is `pi/(pi+0.01*(1-pi))`. It is about **0.091** for `pi=0.001`, versus **0.917** for `pi=0.1`. This is a conditional property of that update's exposure weighting, not a prediction of SNN performance or a requirement that weights be probabilities. Actual recurrent noise need not satisfy the example's independence assumptions.

The [existing cancellation analysis](ContextLoopsAndNumerics.md#cell-composition-can-change-while-the-semantic-value-stays-fixed) shows why this cannot be checked from a semantic sum alone. Equal total added drive in both polarities can leave that sum unchanged while redistributing active credit among cells in the surviving population. The deterministic equal-drive example is not a white-noise model; it isolates a real distinction between retained semantic amplitude and retained contextual identity.

Compare source discovery and effective retained associations across intended noise levels and rare/shared contexts. Excluding every weak contributor could also remove the useful persistent influence required by H-71. No amplitude threshold, noise-origin tag, source trace or classifier-derived learning filter follows from these examples.

Existing-edge adaptation and absent-edge discovery are separate operations. If a useful source already appears in the chosen target's incoming set, changing its weight consumes no new endpoint slot. If it is absent, a rule that only visits retained edges cannot create that association by reinforcement alone. Available unused capacity permits growth but does not identify the right source. A full set introduces a different comparison: use another context-compatible target, replace a justified edge, obtain a larger available set, or defer the change. These alternatives have different effects on learned behavior; none is selected.

The [NuPIC reference](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) excludes already represented sources from its growth candidates and enforces a segment limit separately from adaptation. Its previous-winner candidates, permanence-based removal and segment structure are not adopted. [RigL](https://proceedings.mlr.press/v119/evci20a/evci20a.pdf) likewise evaluates absent connections through an explicitly specified growth criterion, using occasional dense-gradient information. That is a methodological comparison, not a gradient learner or dense search proposed for this application.

Sparse structural learning need not maintain a parameter for every absent edge. [Kappel et al. (2015)](https://papers.nips.cc/paper_files/paper/2015/file/b1a59b315fc9a3002ce38bbe070ec3f5-Paper.pdf) model parameters for potential synapses, including currently nonfunctional ones. In contrast, [DEEP R (Bellec et al., 2018), Algorithm1 and §2](https://arxiv.org/pdf/1711.05136) updates retained connections, replaces removed connections with uniformly proposed dormant ones and explicitly permits storing only active connections. Its backpropagation rule and global connection-count constraint are not adopted. Our static incoming classes impose additional feasibility conditions; neither posterior-sampling guarantees nor degree allocation follow from using similar proposals.

Proposal rejection and membership work are distinct. In the [conditional discovery arithmetic](../research/flow-slot-capacity-analysis.json), let `m` be the probability mass assigned to already represented sources. Independent proposals rejected on membership require `1/(1-m)` attempts per absent source. Uniform proposals over an illustrative 614,400-ID universe with 18,432 retained IDs need about **1.031 attempts**, but a linear row check still averages about **18,717 endpoint comparisons** per accepted source. If credit-weighted proposals place 95% of their mass on retained IDs, twenty attempts are needed on average; row order and mass distribution determine membership work. A positive absent proposal mass is required. These are exact conditional counts, not measured costs or a selected sampler.

Compare discovery at the actual growth cadence, including candidate generation and membership checks, before adding an index. Uniform proposals, credit-weighted proposals and proposals restricted to observed sources have different selectivity and costs. The existing incoming row is sufficient for a simple membership comparison; a large conditional count alone does not justify a hash table, bitmap or reverse adjacency. Growth should demonstrate useful prediction and fit the pool, while reusing existing associations where appropriate.

### Temporal credit under overlapping responses

Persistent activity carries useful history, but a pre-input source measurement need not identify only the immediately preceding observation. The [temporal-credit arithmetic](../research/flow-temporal-credit-analysis.json) uses a deliberately simple token-level reference: unit inputs add exponential tails, with no saturation, noise, cancellation or contextual cell assignment. With token spacing `T` and response half-life `H`, let `r=2^(-T/H)`. Before token `n`, the source mixture is:

```text
c_n = sum(l >= 1, r^l * indicator(token_(n-l)))
```

An update proportional to this source and the current observed target learns a weighted mixture of lagged co-occurrences. Normalizing the stationary linear mixture gives lag weights `(1-r)*r^(l-1)`. With illustrative `H=0.5 s` and `T=50 ms`, the immediately preceding token contributes about 6.7% of that mixture. This is not a model of the actual cells or a claim that the user's dominant-response target fixes every neuron's leak.

For a repeated `A,B,C` sequence, the source amounts before `B` are proportional to `A:1`, `C:r`, `B:r^2`. At that illustrative timing, those ratios are approximately `1:0.933:0.871`. Thus a causal product can strengthen associations from more than the adjacent token even though it never looks into the future. `B` here denotes a token-related population, not necessarily a self-connection on one neuron. Nonadjacent associations and small loops are not automatically wrong; assess whether they help contextual prediction or produce inappropriate readiness.

Prediction horizon is separate from retained context. [Stachenfeld, Botvinick and Gershman (2017)](https://gershmanlab.com/pubs/Stachenfeld17.pdf) define a successor representation as discounted expected future occupancy, rather than just the next transition. Such a broader association can be useful without directly satisfying the provisional next-input readiness comparison.

An [exact three-state reference](../research/flow-temporal-credit-analysis.json) follows `A -> B -> C`, then remains at C. With discount 0.9, future occupancy from A, excluding the present, is `(0,0.9,8.1)`; normalized for comparison it is `(0,0.1,0.9)`. B is nevertheless the certain immediate successor. This is a horizon mismatch, not a claim of inevitable information loss: the complete exact matrix `M=(I-gamma*P)^(-1)` and known nonzero discount recover `P=(I-M^(-1))/gamma`. No matrix storage or inverse readout is proposed. The discount is an analytical example, not the token-response half-life or a neuronal parameter.

[Bono et al. (2023)](https://elifesciences.org/articles/80671) learn that broader quantity using two feedforward layers, place-specific stimulation and a specified potentiation/depression rule. Their equivalence depends on the stimulation and timing model; it does not turn generic Hebbian coactivity into our desired forecast. Keep broader learned associations and useful slow context, while assessing the declared prediction horizon and natural pre-input populations. No TD learner, replay, trace or reward objective is adopted.

Directionality also needs an explicit source/target distinction. The same-time increment `eta*a*a^T` is symmetric on reciprocally available endpoints with equal update factors. It does not supply directional credit by itself. Existing directed topology, different pre/post functions or state histories can supply other asymmetries; this does not assert that the complete graph becomes symmetric.

[Fiete et al. (2010), wide-chain methods](https://fietelab.mit.edu/wp-content/uploads/2018/12/sequence_formation_neuron10.pdf), illustrate why the modeled time unit matters: their binary burst model credits zero-lag coactivity, whereas the continuous-spike version obtains coactive-burst credit from nonzero-lag pairs. The summed-weight examples also use incoming/outgoing synaptic competition and global inhibition to form nondecaying loops. Those results neither replace DMN/token repair nor demonstrate our fading or fixed-semantic fidelity. For the rate comparison, define which interval's coactivity earns credit; copying a spike-window formula does not settle that meaning.

A rate-defined learner need not reproduce a microscopic spike-timing rule. [Kempter, Gerstner and van Hemmen (1999), §§II–III](https://doi.org/10.1103/PhysRevE.59.4498) obtain a rate-product reduction under separated learning/spiking timescales, negligible additional spike correlations and sufficiently slowly varying rates. Those assumptions are not established by storing a rate value or naming an update Hebbian. Here a candidate can specify credit directly at its modeled frame or token boundary and be assessed against H-82/H-83. Biological learning-window values and fine spike timing do not become application requirements through this comparison.

One learning update per token prevents a longer interval from automatically causing more update exposures. It does not make the recurrent state independent of elapsed time. Unequal gaps change the age-weighted mixture even for the same token order. Likewise, a learning-window constant and the duration of a meaningful recurrent response serve different purposes; shortening the latter merely to make a credit heuristic resemble adjacency would discard part of H-71's objective.

| Source-credit candidate | Potential value | Discriminating evidence |
| --- | --- | --- |
| Available recurrent activity | Uses the state already carrying history | Longer-context improvement versus contamination by unobserved alternatives and pacing sensitivity |
| Independently established preceding observed representation | Gives the observed transition an explicit basis separate from generation fallback | Unfamiliar-transition learning and shared-fragment retention; the required representation must actually be available at the update boundary |
| Temporally weighted changes or a narrower credit window | May distinguish recent evidence from persistent contributions | Directional prediction versus loss of useful slow context, noise sensitivity and numerical loss |

These are real-data comparison candidates under H-86. Two neural frames do not retain an arbitrary previous token representation. A known linear recurrence permits an innovation obtained by subtracting its predicted decay, but that subtraction is not a general causal or noise decomposition after nonlinear recurrence and cancellation. No source trace, token buffer, derivative field or causal tag is prescribed.

[Bouchard and Brainard (2013)](https://escholarship.org/content/qt9vp3w0g9/qt9vp3w0g9.pdf) find that preceding sequence statistics modulate later evoked responses in sedated songbird HVC over several syllables. Their integration analysis concerns responses after the target arrives, with trial/site averaging; it does not directly demonstrate prospective readiness. Its temporal extent therefore does not calibrate our isolated-token fading target or prove that longer context has produced a narrower next-token prediction.

[Brea, Senn and Pfister (2013)](https://jbrea.github.io/assets/pdf/brea_et_al.-2013-matching_recall_and_storage_in_sequence_learning_w.pdf) derive learning from specified neural dynamics and explicitly connect their learning window to neural kernels; their hidden/visible distinctions, eligibility traces and global modulation are not adopted here. [Bouhadjar et al. (2022), sequence-speed analysis](https://arxiv.org/html/2111.03456v2) likewise separate the time when prediction is available from timing-dependent structural learning. Their dendritic plateaus, inhibition and numerical timing range do not set our parameters. The applicable requirement is to evaluate credit under the chosen recurrent dynamics and actual token timing while preserving the independent DMN/token maintenance objectives.

### Predictive alternatives and signed cancellation

Several plausible tokens can disagree on a coordinate's sign. A signed mean alone loses information: alternatives `(1,1)` and `(-1,1)` with equal weight have the same mean as a single `(0,1)` candidate. Applying full net cancellation to equal opposite predictive masses also erases that coordinate's readiness evidence. Retaining both signs would avoid this specific loss, but would not by itself preserve which coordinates belong to each complete alternative.

The issue also occurs without opposing signs. Two equal alternatives `(1,2)` and `(2,1)` have the same coordinate-wise distributions as `(1,1)` and `(2,2)`. Every value is positive, yet the valid pairings differ. In the [exact probability reference](../research/flow-prediction-assessment-analysis.json), multiplying the common marginals gives probability 1/4 to all four combinations, placing half the mass on unsupported combinations. This is an artificial information-loss example, not a Flash-token measurement or a proposed decoder.

Compare complete continuation compatibility using the available contextual neural state, as well as individual coordinate compatibility. Same-polarity alternatives help distinguish a lost relationship between dimensions from a predictive-sign cancellation effect. Existing cell identities, recurrent state and learned connections may carry that relationship. A separate binding field, covariance matrix, candidate list or extra frame is not inferred from the example.

H-77 specifies cancellation of active spiking rates. H-85 leaves predictive-phase cancellation open for later controlled comparison; neither preserving both signs nor applying net cancellation is the default. This semantic question does not settle H-78's choice of one phase-aware value versus separate readiness and firing. Either candidate must explain how the required alternatives survive until informative input arrives. No predictive cancellation policy, token decoder, candidate store or probability model is selected.

### Flow learning changes shared recurrence

Prediction improvement and preservation of existing recurrent behavior must be assessed together. The [shared-weight arithmetic](../research/shared-learning-recurrence-analysis.json) illustrates this with two linear units connected in both directions at strength 0.8. Adding an illustrative association increment `eta` to one direction changes the two-step return gain from 0.64 to `0.8*(0.8+eta)`, reaching one at `eta=0.45`. A stronger immediate association can therefore lengthen an existing fading response. This is not a neuron equation, a chosen learning-rate limit, or a claim that every positive update destabilizes the actual nonlinear model.

The effect depends on where an update lies in the graph and on cancellation. A feedforward addition need not close a return path. In a restricted two-polarity aggregate example, same-sign strength `a` and cross-sign strength `b` give signed gain `a-b`; increasing a nonnegative connection can thus increase or reduce the semantic response. Useful small loops remain legitimate under H-71. Neither a new edge nor a short return path is automatically an error.

Uniform normalization is also a substantive behavior change. For an illustrative incoming row `(0.8,0.2,0)`, adding a new weight 0.5 and rescaling the sum to one changes it to approximately `(0.533,0.133,0.333)`. The response to the first source alone drops by one third. A bounded total does not preserve all contextual responses. Normalization, weakening policies and their cadence are empirical candidates; no fixed weight budget, protective edge tags or separate flow network is prescribed.

[Pereira and Brunel (2020)](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2019.00097/full) demonstrate one reason to assess learning conditions alongside later recurrence. In their population-rate model, subtractive incoming-weight normalization does not reliably stabilize sequence learning. Their successful alternative attenuates effective recurrence during stimulation and lets it recover afterward; plasticity remains activity-dependent. This is evidence about that rule and one-population-at-a-time stimulation, not a universal requirement for a gain variable or a result on dense contextual tokens. Compare natural pre-input readiness and retained behavior under the actual learning conditions. H-82 does not require reproducing their autonomous recall.

Learning responsibility also does not supply a missing physical connection. If a source is absent from the chosen target's incoming set, strengthening requires an independently specified slot-assignment or migration operation. Static pool feasibility, source selection and contextual assignment must agree. This establishes an algorithmic dependency, not a new free list, reverse index or allocation policy.

Use effective stored weights when evaluating these effects. A small intended update and its rounded realization can lie on different sides of a return-gain boundary. Compare pre-input sequence matching and narrowing, isolated-token fading, useful later-history influence, activity regulation and external steerability. These shared behavioral checks do not merge flow learning with DMN/token repair or require autonomous continuous generation as a flow-training criterion.

### Joint acceptance across training stages

Different training procedures can act on the same graph without requiring different networks. Their outputs must nevertheless support the required behaviors together. Assess DMN maintenance, isolated-token response and flow prediction using the same stored weights after relevant stages; success immediately after each procedure's own update does not establish that the results coexist.

The [shared-objective reference](../research/shared-learning-recurrence-analysis.json) illustrates a possible failure with one scalar weight and two hypothetical targets, 1 and 0. Each update moves a fraction `eta` toward its target. Alternating the two updates with `eta=0.1` approaches a two-point cycle, approximately `0.5263` after the first and `0.4737` after the second. Reducing `eta` to 0.01 narrows the cycle around 0.5; it does not satisfy either target within 0.1. These are deliberately incompatible scalar targets, not proposed DMN or flow weights and not evidence that the user's behavioral goals conflict.

A deficit-only reference can hide a similar issue: `R(w)=max(w,0.8)` restores a weight after five updates toward 0.2 at rate 0.1 have reduced it to 0.554294. The same restoration recurs each cycle even though every post-repair snapshot is 0.8. This is an explanatory map, not H-63's chosen repair algorithm. Conversely, different available source patterns can permit one shared row to meet different targets: `(0.8,0.2)` responds appropriately to `(1,0)` and `(0,1)` without separate networks.

If a real comparison exposes repeated undoing, distinguish incompatible imposed targets, inadequate contextual assignment, forgetting under the chosen update, slot limits and numerical loss. Compare the existing target definitions, update scopes and training cadence where they address the observed cause. Interleaving or smaller steps may help compatible tasks, but cannot make contradictory constraints simultaneously true. No protected connections, per-edge role tags, replay store or additional consolidation stage follows from this reference.

### Capacity demand depends on contextual assignment

For the one-weight-per-source/target reference, a target's live degree is the size of the **union of retained source IDs** across its associations. Repeatedly strengthening the same source does not add a slot; assigning different sources does. Fractional recruitment changes their contributions, not the integer storage cost of retaining an endpoint. If the same endpoints require context-specific weights, that would be additional semantics, not an implicit benefit of another slot.

The [conditional source-union arithmetic](../research/flow-slot-capacity-analysis.json) illustrates why repeated selection matters. Independently selecting three of sixty source identities and retaining all selected edges gives an expected union of about 33.6 after sixteen selections and 57.7 after sixty-four. This is neither a proposed encoder nor measured training demand. Context-dependent reuse, target assignment and edge retention determine the actual distribution; neither token count nor one transition's fan-in gives it alone.

The [incoming capacity condition](IncomingConnectivity.md#static-capacity-feasibility) must hold for that distribution, beyond the sum of all live edges fitting the pool. The 16-class candidate has 327,670 sets larger than 100 slots. If all 614,400 neurons participate, at least 286,730 must therefore require no more than 100 retained inputs. Giving every neuron 101 inputs would fail this assignment condition even though its 62,054,400 edges fit within the total reserved slot count. This is a property of the provisional pool, not a learning quota or a reason to change it now.

Future real-data comparisons should distinguish wrong contextual assignment, insufficiently selective integration, missing source discovery, insufficient effective strength and class exhaustion. Favor the simplest candidate that improves pre-input prediction while preserving shared recurrence and a feasible retained-degree distribution. More capacity alone does not establish better prediction, and representation-only migration must preserve effective weights rather than change their meaning with the destination class.

### Bounded reinforcement and the meaning of an exposure

Bounds alone do not make repeated reinforcement selective. For a normalized reference weight, `w_next=min(1,w+eta*c*y)` reaches its upper bound after enough positive pair occurrences. The soft positive-only rule `w_next=w+eta*c*y*(1-w)` tends to the same upper bound under indefinitely repeated positive binary occurrences. Different frequencies change how quickly this happens. This conditional result does not reject every bounded Hebbian rule; it identifies what a positive-only baseline fails to explain.

Saturation is not necessarily a failure when the intended learned quantity is whether an association exists. With zero initial weights and recurring one-hot source/target pairs `(1,0)->(1,0)` and `(0,1)->(0,1)`, those positive-only rules approach the identity matrix and retain selective responses. A single shared source paired with either of two targets instead approaches two unit weights, preserving both possibilities without encoding their frequencies. These conditional limits do not establish behavior for dense graded activity, incidental coactivation or shared recurrence. H-82/H-83 require useful matching and contextual narrowing, not a calibrated probability for each weight.

The inspected [NuPIC reference](https://raw.githubusercontent.com/numenta/nupic/master/src/nupic/algorithms/temporal_memory.py) separately controls punishment of an unobserved predicted column: `predictedSegmentDecrement` defaults to zero, while adaptation of an observed segment can still weaken inactive-source synapses. This is a concrete distinction between weakening roles, not a recommendation to copy either setting. Compare retained possible continuations and irrelevant readiness separately from frequency-sensitive strength; neither unconditional punishment nor permanent preservation of every association is prescribed.

The [update-law arithmetic](../research/hebbian-update-law-analysis.json) compares three affine alternatives. For this derivation, `c,y` are binary, their pairs are independent across exposures, assignment is fixed and independent of the current weight, and `0<eta<1`:

| Update | Stationary mean under those assumptions | Interpretation to examine |
| --- | --- | --- |
| `w_next=(1-eta)*w+eta*c*y` | `E[c*y]` | Joint co-occurrence, with decay on every learning exposure. |
| `w_next=w+eta*c*(y-w)` | `E[c*y]/E[c]`, when `E[c]>0` | Association conditional on eligible source activity. |
| `w_next=w+eta*y*(c-w)` | `E[c*y]/E[y]`, when `E[y]>0` | Association conditional on target responsibility. |

If a source occurs on 1% of exposures and its target follows on half those occasions, the first two means are 0.005 and 0.5. Neither is automatically the right neural weight: the real quantities are graded, multiple sources interact, and contextual assignments depend on learned state. With graded bounded `c,y`, the analogous ratios are weighted moments, not token probabilities. The distinction explains why scope and timing belong in the learning rule. Updating only positive pairs or only selected rows can change the exposure distribution and invalidate an intended conditional interpretation.

[Bouchard, Ganguli and Brainard (2015)](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2015.00092/full) relate learned transition statistics to the locus of competition under specified rules. Their binary derivation uses one active source category per target event; recurrent and spiking comparisons use strong external teaching. Competition is a learning constraint, not storage ownership: incoming SoA can support different exposure and weakening rules. With multiple simultaneous sources, normalized co-occurrence need not equal a probability of each source being present. Incoming layout therefore does not select backward inference, and contextual prediction does not require outgoing storage.

A related candidate introduces relative weakening strength `beta`:

```text
w_next = w + eta*c*(y*(1-w) - beta*(1-y)*w)
```

For `c,y,w` in `[0,1]`, `beta>=0` and `eta*max(1,beta)<=1`, this reference keeps the weight in range. Under the binary assumptions its mean is `p/(p+beta*(1-p))`, where `p=Pr(y=1|c=1)`. At `beta=1` it is the source-enabled affine rule; at `beta=0` it has positive-only saturation. These normalized units, coefficients and bounds are comparison parameters, not physical synaptic scales. Weight decreases do not introduce inhibitory connections or delete endpoint slots.

H-83 does not require every valid branch to have the same strength. Gradual frequency-sensitive updates can retain several branches without treating one absent observation as proof that another branch is impossible. Conversely, strengthening the last observed branch until it dominates is not evidence of context-dependent narrowing. The comparison needs shared and disambiguated histories, including rare contexts and continuations. No update law can recover an earlier distinction that the available contextual representation has already erased.

### Prediction-error modulation as a comparison

An association statistic is not automatically an additive prediction coefficient. The [exact finite-pattern reference](../research/hebbian-update-law-analysis.json) uses two always-active sources and a target value of one. The source-enabled affine rule has mean weights `(1,1)`, giving a raw sum of two; weights `(0.5,0.5)` give one. These are fixed-source, fixed-assignment linear calculations. A saturating response changes the comparison, and errors evaluated at mean weights are not the expected errors of a fluctuating learner.

A second candidate for the provisional procedure's adaptation step is to modulate source credit by the discrepancy between a specified predictive response and its observation-conditioned target. For a one-step linear reference:

```text
y_hat_j = sum_i w_ji * c_i
L       = 0.5 * sum_j (y_j - y_hat_j)^2
Delta w_ji = eta * (y_j - y_hat_j) * c_i
```

This is the gradient of that reference loss when `c` and `y` are fixed. The target's other incoming sources now affect each update through `y_hat_j`. In another exact example, a source present in both contexts receives weight zero while a second source distinguishing the target receives weight one; the source-enabled affinity means instead give `(0.5,1)`. This illustrates different objectives, not proof that the error-modulated rule is the better SNN learner. Nonnegative-weight bounds, source discovery and the actual nonlinear response still need to be respected.

[Millidge et al. (2024)](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011183) derive Hebbian updates using prediction-error signals in a specified temporal predictive-coding model. Its inference process, error representation and timing give those products meaning. The result motivates distinguishing pure co-occurrence from error-modulated association; its hidden-state, circuit and learning assumptions are not adopted.

For the same fixed linear reference, a simultaneous update gives `e_next = (1-eta*sum_i c_i^2)*e`. With nonzero error and source energy, squared error decreases when `0 < eta*sum_i c_i^2 < 2`. At unit source values, `eta=1/128` decreases error for 100 credited sources but overshoots for 18,432. These are conditional arithmetic sizes, not measured activity or recommended rates. The relevant quantity is actual squared source credit, not reserved slot capacity. Compare a sufficiently small fixed step with a step adjusted to that source energy if needed; the latter can use a transient sum during the learning traversal, with additional arithmetic but no implied stored scale field. Bounds, changed assignments and nonlinear responses need their own assessment before transferring this identity. [Quantized row updates](ContextLoopsAndNumerics.md#prediction-error-updates-on-a-quantized-row) can remain unchanged or cycle despite an ideal decreasing-error step; the stored update is the relevant comparison.

Where the mismatch is measured matters. In a conditional H-77 example with fixed positive total one and a target negative output one, small gradient steps on separate post-cancellation population errors approach the cancellation boundary without crossing it. A signed-net error gives a different path and crosses it. The artifact gives exact assumptions and closed forms. Neither loss is selected: a signed-net score omits cell-level context, and H-78/H-85 do not yet determine how predictive readiness interacts with cancellation.

The comparison should therefore define its target and observed response before choosing an update. It must preserve H-83's legitimate alternatives rather than automatically treating every unobserved branch as erroneous. The temporary error can be ordinary training arithmetic; error neurons, extra fields, a recurrent-history gradient or a new optimizer do not follow. This flow candidate learns from sequence observations, independently of the prescribed next-group deficits used in DMN/token maintenance.

### Learning through active-rate cancellation

If a comparison evaluates a loss after [H-77 cancellation](SignedPopulationEncoding.md#cancellation-arithmetic-and-the-semantic-residual), its derivative is not generally an independent error for each raw receiving cell. For one minicolumn with positive provisional rates `p_i`, negative rates `m_k`, totals `P>M` and surviving outputs `q_i=p_i*(P-M)/P`, let `g_i=dL/dq_i`. The [one-operation arithmetic](../research/cancellation-properties-analysis.json) gives:

```text
mu = sum_i(g_i * p_i/P)       beta = M/P
dL/dp_k = ((P-M)/P)*g_k + beta*mu
dL/dm_k = -mu
```

The opposite winning polarity is symmetric. Thus even a cell on the suppressed side can affect the objective through cancellation. The common term `mu` is a temporary population calculation; no stored dense derivative matrix follows. In this branch each raw gradient's magnitude is bounded by the largest output-gradient magnitude. At equal totals the cancellation map is generally nondifferentiable, though a particular composed loss can still be smooth.

For a squared cell-pattern loss, provisional positive rates `(1.5,0.5)` and negative rates `(0.75,0.25)` produce `(0.75,0.25)` on the surviving side. Against target `(0.5,0.5)`, the raw positive derivatives are `(3/16,-1/16)` and both negative derivatives are `-1/8`. The signed total already matches the target total; a signed-total error alone misses the contextual pattern discrepancy. This is an exact conditional example, not a selected target assignment or learning rule.

Numerical form matters even before storing a weight update. With a normal FP32 total `P=2^-80`, explicitly forming `P*P` underflows in FP32; an expanded derivative containing `M/(P*P)` can therefore fail despite bounded mathematical derivatives. The ratio form above remains finite in the recorded example. It does not establish general numerical accuracy or choose a boundary derivative.

These calculations concern active-rate cancellation. Applying them to predictive readiness would depend on the still-open H-85 comparison. They also do not compute a whole-sequence gradient: changing a weight affects future states, assignments and losses. [Bellec et al. (2020), equations1–4 and13–29](https://www.nature.com/articles/s41467-020-17236-y) distinguish an exact recurrent-gradient factorization from its approximate online learning signals; their eligibility expressions depend on the neuron dynamics. Neither that factorization nor a local error product supplies a generic trace layout for this model. Compare the simpler observation-based learner before adding longer-range credit machinery.

### Learning exposure and incoming-edge work

The learning rule's exposure set determines which weights must be considered. These [conditional traversal counts](../research/execution-work-arithmetic.json) concern retained edges; they do not assume every reserved slot is occupied or select an auxiliary index.

| Reference rule | Relevant retained-edge scope |
| --- | --- |
| Decay on every exposure: `(1-eta)*w+eta*c*y` | All weights decay, including pairs with zero `c*y`. Visiting positive pairs alone changes the rule. |
| Source-enabled: `w+eta*c*(y-w)` | Edges from credited sources. Incoming lists do not directly enumerate all their targets. |
| Target-enabled: `w+eta*y*(c-w)` | All incoming edges of responsible targets, including uncredited sources subject to weakening. |
| Positive-only: `w+eta*c*y*(1-w)` | Only pairs with both roles nonzero change. Scanning selected incoming rows still reads source IDs that receive no credit. |
| Linear prediction-error reference: `w+eta*(y-y_hat)*c` | Incoming associations of compared targets with nonzero mismatch and credited sources. A target assigned zero can still have prediction error; finding the relevant rows and sources also costs work. |

An eight-target reference with 32 edges illustrates the difference. Two credited sources and two responsible targets produce 32, 12, 16 and 4 changed weights, respectively, under the four rules. The two selected targets own sixteen incoming edges, twice the estimate obtained by multiplying their neuron fraction by total edges. Actual retained degrees and available traversal matter; fewer weight writes do not necessarily mean fewer endpoint reads.

Compare work at the specified token-learning cadence separately from neural frames. Reusing a recurrent gather may save work only if its source snapshot and the target's learning responsibility are available at the required point; preserve prediction-before-update and complete-transition publication. Zeroing small rates for speed changes credit semantics, and the regime classifier's density filter is not automatically a learning filter. Source discovery, duplicate checks and migration add separate work. No reverse adjacency, lazy decay state, trace, eligibility threshold or new bookkeeping array is implied; first compare the simplest incoming traversal for the chosen rule.

### Learning time and retention of associations

Repeated affine updates toward the same target compose with effective coefficient `1-(1-eta)^n`. For `eta=0.01`, one, ten and one hundred updates give coefficients 0.01, about 0.0956 and 0.634. Thus applying a nominal per-token update every neural frame makes presentation duration alter learning substantially. A physical-time version can use `eta(Delta)=1-exp(-lambda*Delta)` for this affine law; one update per observed token instead defines event-based exposure. Both are candidates. Neither makes the actual contextual dynamics independent of token timing, and neither requires a stored trace by default.

Synaptic retention under continued learning is distinct from the half-life of a token's active response. Even a stationary weight distribution can contain rapidly changing individual associations. [Van Rossum, Bi and Turrigiano (2000)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6773092/) distinguish stable weight statistics from competition in their weight-dependent STDP model. [Billings and van Rossum (2009)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2694112/) explicitly examine retention under continued plasticity. Their spike rules and inhibitory network remedies are not imported here. [Oja's original analysis](https://neurophysics.ucsd.edu/courses/physics_171/Oja_1982.pdf) also illustrates that a stabilizing Hebbian term has a specific learning objective under its assumptions; its principal-component result is not proof of contextual sequence learning in fixed semantic populations.

Ongoing activity does not automatically mean ongoing weight updates. [Higgins, Graupner and Brunel (2014)](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003834) study background-driven changes with a continuously active calcium-based plasticity law; their retention depends on that law and its parameters. This motivates stating when a candidate learner is enabled. It does not require importing calcium, bistability or inhibitory circuitry. Here background support can remain active while a learning procedure is disabled; during enabled learning, credit still needs to distinguish useful context from irrelevant activity. No universal noise-exclusion or plasticity-gating formula is selected.

[Cui, Ahmad and Hawkins (2016), author draft v2, §4.2](https://arxiv.org/pdf/1512.05463v2), deliberately replace learned sequence endings to assess adaptation. Success there does not establish retention of still-valid alternatives: replacement and concurrent ambiguity are different tasks. Their §4.4 varies shared-subsequence length; sequence order alone is not elapsed memory duration under our intervening neural frames. Comparisons here should identify whether an association remains valid, is deliberately replaced, or must coexist with DMN/token behavior. No universal preservation of every historical association, automatic change detector or new nonstationary-learning requirement follows.

Compare retained predictions before and after further sequence learning, alongside fixed-weight assessment, token fading and external steerability. Bounded weights do not bound every recurrent response. Numerical update visibility and variability must also be checked: [low-bit repeated updates](ContextLoopsAndNumerics.md#repeated-learning-on-a-low-bit-grid) can differ materially from the ideal equations. These checks do not select a global forgetting rate, normalization controller, plasticity schedule or extra per-edge state.

### Bounded-synapse memory is a separate comparison

[Fusi and Abbott (2007)](https://columbia.edu/cu/neurotheory/Larry/FusiNatNeuro07.pdf) examine traces in synaptic weights under ongoing modifications, starting from an equilibrium distribution. Their ideal observer directly inspects the weights. Benefits from smaller updates depend on the bounding rule and potentiation/depression balance; extra distinguishable levels alone do not supply a general retention guarantee. This is neither active-loop persistence nor a demonstration of natural pre-input prediction.

A [finite-weight arithmetic reference](../research/weight-update-precision-analysis.json) makes that sensitivity concrete. A weight moves up or down one equally spaced level at Poisson learning opportunities, remaining at a boundary when a move would exceed it. With equal up/down probabilities, increasing from 16 to 256 levels changes the slowest distribution-relaxation time from about 52 to 13,281 expected opportunities. With up probability 0.55, the corresponding values are about 41 and 197. These are conditional linear-distribution modes, not task memory lifetimes, neural frames, seconds or measured FP4/FP8 behavior. More representable levels do not specify the actual learning dynamics.

In that fixed-range reference, a one-level move is `1/(M-1)`: 256 levels use seventeen-times smaller physical updates than sixteen. The slow distribution mode is also different from reaching a distant weight. At up probability 0.9, the expected first arrival from the bottom to the top takes about 18.59 opportunities with sixteen levels and 318.59 with 256, although both slow modes are near 2.5 opportunities. Exact first-step identities are recorded in the same artifact. These comparisons separate update units, starting condition, acquisition and retention; they do not measure task learning or hold the physical update size fixed across formats.

[Benna and Fusi (Asilomar 2017)](https://ctn.zuckermaninstitute.columbia.edu/sites/default/files/content/Publications/2018/Benna%20%28Fusi%29%2C%20Efficient%20Online%20Learning%20with%20Low-Precision%20Synaptic%20Variables.pdf) improve retention through multiple interacting synaptic variables. A low-bit effective weight is not their complete stored learning state. Their elapsed units count plasticity events, not physical time; their memory comparison uses an ideal observer. The paper also distinguishes stronger signals caused by correlated inputs from improved information storage. Its consolidation machinery is not adopted here.

For this application, compare actual pre-input sequence matching after additional learning, including successful acquisition of new associations. Account for every proposed learning variable and its update work alongside the simpler wider-weight alternative. A longer-lived weight trace that prevents needed learning, or that the recurrent network cannot use, does not meet H-82/H-83. Existing neurons, connections and appropriate arithmetic remain the first comparison; neither a memory-capacity scaling law nor a small inference weight justifies hidden per-edge state by itself.
