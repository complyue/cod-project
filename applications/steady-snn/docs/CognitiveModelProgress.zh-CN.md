# SNN 认知模型设计进度

修订 2 · 2026-11-05 · 讨论要点与阶段性研究结论

[English version](CognitiveModelProgress.en.md)

当前建模以一条前提为中心：每个皮层柱单元（CC）都承载完整概念动力学空间的一份近似副本。概念的内容来自经验及其对后续预期的影响，由训练形成的连接和激活过程承载；token 向量负责提供共同的表达与访问接口。接下来的关键问题，是有限精度的发放率模型怎样形成抽象、支撑协同推演，并保留 spike 时机所带来的有效协作。

“观察一个长方形框”把这些问题落到同一认知场景：局部视觉模式如何组成物体，物体如何与身体姿态联系，系统又如何觉察和调整自己的观察。《成唯识论》的四分说在这里提供讨论框架；这并不证明网络已经具有意识，也不把四组 CC 认定为四分的生物学对应物。

## S2 长方形场景中的四分
<a id="s2"></a>

下列分组说明各组 CC 在这次认知活动中的主要作用。依照 CM-03，各组仍拥有共同的完整概念空间，不按组分割概念库。

| 四分 | 输入与作用 | 场景中的语义 |
| --- | --- | --- |
| 相分 | 将一批 CC 指定为二维视场中的“模式像素”位置，表达局部图样，而非直接表达视网膜颜色像素。 | 左下角位置出现指向左下角的直角，两边延伸；其它位置分别呈现空白、横线、竖线或角框。 |
| 见分 | 高级视觉区域的 CC 接收视场模式，形成物体层面的识别。 | 视场正中间有一个中等大小、横向的长方形。 |
| 自证分 | 空间感区域综合视觉结果与身体、肌肉、头部和眼位输入；双眼视觉还可引入距离。 | 身体正坐，头向左扭 45°，眼位平视，正在面对一个横向长方形。 |
| 证自证分 | 自我觉察区域接收前述信息，形成对当前观察及其关注点的表征。 | 我在看左前方的长方形框架；它很“方”，边直、角利；我好奇它是什么材质。 |

自我觉察再反馈给空间感区域，可以形成“主体是我，行为是好奇地观察长方形”的语义。一个待检验的功能标准是：这种表征既能改变后续观察，也能被实际收到的信息和实际发生的行为纠正。两组活动彼此一致，本身还不足以说明已经建立这种联系。

场景必须分清参照系：一个角在视场哪里、位于物体的哪个部位、两条边朝哪里延伸，是三件事。“平视”也不确定眼球的左右转角，仅凭头部转角不能推出物体相对身体的方位。坐标转换和属性归属都要由模型解决。

四分说讨论的是一次认知中相互关联的作用，并未规定四级神经解剖流水线 [R01]。这里的分组属于应用建模假设；能够表达自我描述与具有主观体验，也应分别看待。

## S3 概念怎样从经验中形成
<a id="s3"></a>

本设计按用户提出的边界处理静态 token 表：概念的经验与推演内容基本不由它提供。这并非断言预训练向量毫无统计关联，而是明确学习责任。长方形的名字可以成为访问线索，却不能自行给出陌生情境中与长方形有关的预期。

概念内容包括沿边观察会遇到什么、视角变化会怎样改变所见，以及继续观察或行动怎样区分空框与实心面板。仅凭形状不能确定材质和是否实心。LLM 可以提供描述或教学材料，但 SNN 仍须形成自己的动力学；把完整 LLM 搬进来，也不等于把概念动力学直接转移到我们的结构中。

当前候选理解是：一个概念对应一族相关的循环激活路径，以及这些路径随输入和上下文发生的转变。除了“能持续活跃”，还要说明它在什么情况下被唤起、接下来预期什么、何时结束或转向。各 CC 的连接、经历和当前输入可以不同，但应拥有大体对应的这类组织。

抽象的价值在于，若干长方形的经验能够改善对另一些长方形的预期。当下活动只需保留位置、朝向及任务关心的例外，已学连接则提供通常成立的关系。把不同经历分别记住，再统一贴上“长方形”标签，还不足以说明发生了这种迁移。

固定语义坐标并不妨碍学习上述动力学，也不要求为每个概念另开维度、在 CC 内引入物理几何，或把概念硬分给不同 CC。各感受区域接受的经验不同，怎样仍让每个 CC 保有完整概念空间，是训练必须回答的问题；共用 token 表不会自动做到这一点。

## S4 稀疏活动下的容量与精度
<a id="s4"></a>

需要分别衡量三种能力：**存下多少概念动力学、当下能表达得多细、一次推演能保持多少关系可用**。5,120 维是共同语义表示的候选规模，不能直接当作全网认知容量的测量结果。

按当前 5,120 ×（60 + 60）的规模，每维只参与一个细胞，共需 5,120 个，占 614,400 个神经元约 0.83%，但各维都可能非零。这只是计数示例，不能证明精度够用或传播稳定；它说明“神经元稀疏”不能直接换算成“多数语义维度不可用”。

参与细胞的数量、rate 大小、语义读出的非零维数，是不同指标。哪个细胞参与以及以多大 rate 参与，都可能携带信息。稀疏编码可容纳许多不同模式，同时表达时却仍受干扰和可辨程度限制 [R05]。能量研究支持考虑活动预算，但不能给本模型直接定一个普适的健康激活比例 [R04]。

若第 i 维的可用值域宽度为 R_i，而某项后续判断要求两值至少相差 δ_i，均匀划分时可粗估 `Q_i ≈ 1 + R_i / δ_i` 个层级。δ_i 取决于数值运算、噪音、抵消、循环演变和观察时长，不一定等于单个神经元的一档数值精度。维度间相关性与活动约束也意味着，不能把各维的名义层级都视为可独立使用的信息。

“7 ± 2”是研究容量的线索，不是预设槽位数。Miller 区分了不同任务的容量，Cowan 则在更严格条件下讨论约四个组块 [R02]。群体噪音和率失真理论更直接地涉及负荷、精度与误差代价 [R03]。这些研究都未证明人脑工作记忆会耗尽某个 5,120 维语义空间。

时间复用可能让不同内容轮流进入较强的活动状态，以较弱活动或另经论证的状态保留上下文。但两次访问之间，物体身份、关系和推演进度必须仍能接上。只有动力学确实保留或积累了有效信息，增加时间才有帮助。振荡子周期模型和间歇性工作记忆活动提供了参考，并未替我们选定时钟或保持机制 [R06]。

设神经状态为 s，语义读出为 x = D(s)，更新为 s' = F_W(s, u)。即使 x 相同，参与细胞的上下文身份仍可不同，后续演变也可不同。因此，“5k 足以充当接口”比“5k 已完整确定推演状态”弱得多。多个 CC 又增加了状态与交互空间，全网为何出现统一的推演瓶颈仍需解释。近似副本还可能共享误差，数量增加不等于精度同比提高 [R07]。

## S5 发放率模型中的时序协同
<a id="s5"></a>

每个神经元保有有限精度的 rate。活跃或不活跃只是对状态的归类，不能代替完整状态。现在需要研究的是：单次 spike 的时机所产生的哪些作用，必须在连续分级的活动演变中留下来。

一个分析例子：两路输入在 20 ms 内各发放一次，窗口平均都是 50 Hz。若每次输入贡献 1，按 5 ms 时间常数指数衰减，阈值取 1.5，那么同时到达可达到 2，相隔 10 ms 则峰值约为 `1 + exp(-2) = 1.14`。平均 rate 相同，结果仍可不同。这个例子只说明信息损失，不指定生物参数，也不把 SNN 改成逐 spike 仿真。

有关联的时序包括：输入在目标处是否重叠、先后次序、传输延迟、突触近期使用情况，以及接收方的状态。发放不同步也可能到达同步。时机既影响当次传播，又影响连接怎样学；复现了其中一个，不代表另一个也成立 [R08—R13]。

值得比较的方向是：对 rate 历史作因果滤波，再由目标的非线性响应决定更新。它可以保留所解析时间尺度上的变化与重叠，却不能区分已经压成同一份 rate 历史的 spike 模式。相位或相关性摘要同样只是保留部分信息，各有遗漏范围。

对简化的电流加权输入，有 `Var(Σ w_i a_i) = Σ w_i² Var(a_i) + 2Σ_{i<k} w_i w_k Cov(a_i,a_k)`。各路均值不足以确定共同波动，而且一般有 `E[F(I)] ≠ F(E[I])`。这解释了平均化可能丢掉什么，不意味着要存协方差矩阵，也不意味着二阶统计已经足够。

应一起评估 rate 的含义与平均窗口、更新间隔、积分与恢复时间、保留的历史、延迟、数值格式及学习归因。已有 rate 降阶方法存在适用边界，低噪音下出现 spike 锁定就是一例 [R14]；这与本模型计划中的低噪音心流状态直接相关。两帧轮换解决的是快照一致性，不能自动表达精细的同时性或任意延迟。

### S5.1 连续神经元状态与已确认的拉取架构
<a id="s5-1"></a>

建模的目的，是避免误用或裁掉可能使能知识学习、概念泛化和协同计算的生理机制，而不是把精确重建单神经元生理过程作为独立目标（H-95）。增加模型或运行时复杂度，须能说明它对这些能力有什么作用。

H-93 明确：同一源神经元的连续 AP 来自同一套持续演化的状态，不能先把各次 AP 当作彼此独立的波形，再拼接尾部。全局 AP 曲线可以简化描述放电阶段的输出，但固定曲线不意味着各次 AP 的动力学独立。上次 AP 完成时间可以概括部分恢复状态；是否需要适应、能耗等更多历史，取决于所选机制。不能由多帧 AP 自动推出独立尾部对象、队列或线性叠加规则。

H-94 正式确认双帧连入拉取：每个下游遍历自己保存的入连，从只读帧 A 拉取源神经元 effect，结合自身状态计算 B；整步完成后统一发布 B，再交换两帧。源和下游只是同一神经元在不同连接中的角色。读取 effect 不推进、不消耗源状态；无论现算还是缓存，所有下游读到的都须是同一源时间视图。单帧 AP 和多帧 AP 共用此架构。

上游 scatter、出连遍历和 push queue 不作为默认传播路径；采用它们属于改变已确认架构的设计变更。将来若选择额外传导延迟，可以考虑由下游读取有界源历史，但这不等于选定历史字段、队列或额外整网状态帧。10 kHz 扫描、不应期公式、AP 时长、曲线归一化、神经元方程和学习规则仍各自待定。实现不得因覆盖时间戳或复用数组而意外改变所选的连续动力学及下游响应。

## S6 候选机制及其代价
<a id="s6"></a>

| 候选 | 希望保留的作用 | 边界与代价 |
| --- | --- | --- |
| 当前 rate 配合非线性整合 | 作为基线，判断哪些行为确实需要更多信息。 | 相同保留状态无法区分已丢失的历史。 |
| rate 的因果滤波 | 对近期变化及可解析的时间重叠产生不同响应。 | 时间常数与离散化需要验证，窗口内丢失的时机仍不存在。 |
| 适应或传输历史 | 区分反复使用与恢复后的响应。 | 增加状态前，须明确作用及归属。 |
| 有效延迟或相位关系 | 让特定到达组合或 CC 组之间发生协作。 | 需要时间参照与信息保持；未选择逐边延迟字段或全局振荡器。 |
| 到达集中度或相关性摘要 | 区分部分均值相同、共同活动不同的输入。 | 可能漏掉次序或多峰结构；逐输入对存储可能很贵。 |
| 对时机敏感的学习迹线 | 保留对有关时间关系的学习归因。 | 不能仅用 Hebbian 或 STDP 名称代替规则；rate、次序和协同条件仍须明确。 |

保留各细胞的上下文身份。群体降阶研究可以借鉴方法，但不意味着把每个 minicolumn 合成一个 rate [R15]。每个源细胞共用一份历史与每条边独立保留历史，代价不同。协作还须兼顾语义多样性、正常淡出和外部可驱转性，不能以全网同步为目标。

| R05 | [Tsodyks 与 Feigel'man 1988](https://weizmann.esploro.exlibrisgroup.com/esploro/outputs/journalArticle/The-Enhanced-Storage-Capacity-in-Neural/993263100803596)；[Olshausen 与 Field 1996](https://www.cns.nyu.edu/~tony/vns/readings/olshausen-field-1996.pdf) | 稀疏联想存储与自然图像稀疏编码展示不同收益；Hopfield 假设及学习感受基底均不能直接照搬。 |
| R06 | [Lisman 与 Idiart 1995](https://www.ucl.ac.uk/brain-sciences/sites/brain_sciences/files/lisman95-oscillatory-memory.pdf)；[Lundqvist 等 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5220584/) | 子周期模型与猴工作记忆间歇活动支持研究时间复用，不要求固定七槽时钟。 |
| R07 | [Moreno-Bote 等 2014](https://www.nature.com/articles/nn.3807) | 特定相关结构会限制群体信息；增加副本或降低平均相关性，都不保证精度提高。 |
| R08 | [Usrey、Alonso 与 Reid 2000](https://pmc.ncbi.nlm.nih.gov/articles/PMC6772311/) | 猫丘脑—皮层记录中，同轴突和跨轴突输入的协同窗口不同，约为 15 与 7 ms；尺度受实验条件限制。 |
| R09 | [Tsodyks 与 Markram 1997](https://pmc.ncbi.nlm.nih.gov/articles/PMC19580/) | 记录与模型表明，突触短时压抑影响 rate 与时间相干信息的传递；短时效能不等于长期权重。 |
| R10 | [Branco、Clark 与 Häusser 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC6354899/) | 模式化刺激显示树突可区分输入顺序；相关生物机制不包含在简单加权和中。 |
| R11 | [Sjöström、Turrigiano 与 Nelson 2001](https://plasticity.muhc.mcgill.ca/DataPage/PDFs/Sjostrom_Neuron_2001.pdf)；[Pfister 与 Gerstner 2006](https://pmc.ncbi.nlm.nih.gov/articles/PMC6674434/) | 皮层可塑性共同受 rate、时机与协同影响；三 spike 模型在特定假设下联系时序学习与 rate 学习，不能推出通用规则。 |
| R12 | [Womelsdorf 等 2007](https://pubmed.ncbi.nlm.nih.gov/17569862/)；[Zandvakili 与 Kohn 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4545497/) | 相位关系和协调活动与有效通信有关；V1 的协调模式并未原样贯穿所考察的各级下游。 |
| R13 | [Izhikevich 2006](https://www.izhikevich.org/publications/spnet.htm) | 延迟与可塑性模型可产生时间锁定但不同步的群组；群组计数不等于本模型可用概念容量。 |
| R14 | [Ostojic 与 Brunel 2011](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1001056) | 滤波加非线性可在一定条件下近似 rate 响应；低噪音锁定及更完整的 spike 统计暴露其边界。 |
| R15 | [Schwalger、Deger 与 Gerstner 2017](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005507) | 介观方程在群体假设下保留历史与有限规模波动；不能据此抹去细胞的上下文身份。 |

建议先比较小型时序敏感连接结构，再考察学得的序列区分、长方形任务，最后扩展到多个副本。研究时机差异时保持平均 rate 一致；平移输入相对帧边界的位置，检查是否只是离散化造成效果。候选模型只能使用其声明保留的信息，不能借用参考模型的隐藏 spike 时刻或未来标签。

定量结果另行记录单位、假设、数值格式和来源条件，与本文的讨论综述分开。字段、滤波、延迟或学习规则的变动各有其设计范围。本追踪不授予自举、构建、测试或仿真运行权限。
